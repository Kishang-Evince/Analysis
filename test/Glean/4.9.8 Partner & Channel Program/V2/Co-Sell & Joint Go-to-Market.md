# 4.9.8 Co-Sell & Joint Go-to-Market — Independent Research Test Guide

**Purpose:** Verification of every claim in the companion research doc [V2/Co-Sell & Joint Go-to-Market.md](../../../../Glean/Combined/4.9.8%20Partner%20&%20Channel%20Program/V2/Co-Sell%20&%20Joint%20Go-to-Market.md). The core finding there is that all three cloud marketplaces are real but lack disclosed formal co-sell mechanics, the Google Cloud partnership page is stale (dated January 2023), and the accreditation-count discrepancy from an earlier field is likely same-day conflicting press reporting rather than genuine two-week growth. This guide's job is to validate the marketplace listings directly, get a currency check on the Google Cloud relationship, and get real answers on MDF and target-account mapping. Written so someone with no prior context on this project can pick it up and run it — mostly marketplace checks and partner-manager questions, no developer access needed.

**Sr No mapping:** Sr No 1-9 below map 1:1 to the same Sr No in the companion research doc's claims table [Combined/V2/Co-Sell & Joint Go-to-Market.md](../../../../Glean/Combined/4.9.8%20Partner%20&%20Channel%20Program/V2/Co-Sell%20&%20Joint%20Go-to-Market.md#claims-sr-no-1-9-mapped-to-test-guide) — same number, same claim, doc-sourced there / tenant-tested here.

**Effort column:** each row lists an estimated time to complete plus a difficulty tag — `Easy` (a quick page check) or `Hard` (needs a written vendor answer) — so you can plan which rows to tackle first.
