**Goal:** Draft/publish/restore cycle.

| Step | Action | End-user sees |
|---|---|---|
| 1 | Publish v1 | v1 behavior |
| 2 | Draft edit → publish v2 | v2 behavior |
| 3 | Restore v1 from history → publish | v1 restored |

Note: sharing/permission changes **not** versioned.
