# Marketing event description

Turn your internal event brief and sales resources into an on-brand event description.

## Overview

Event marketers often juggle scattered documents - briefs, agendas, audience notes, internal resources - before writing a single sentence of event copy. The marketing event description agent brings everything together. It reads the event brief, identifies key logistics, determines who the event is for, and generates multiple description options. Then it refines the strongest version into a polished, ready-to-use description that fits your tone and highlights why the event matters.

## See it in action

## Capabilities

-   Gives marketers a strong, on-brand event hook in minutes so they can move quickly from planning to promotion.
-   Creates fresh, on-brand event copy that matches your tone and audience.
-   Minimizes rework by keeping dates, times, venues, and rules aligned with the event brief.

## Agent workflow

### Step 1: Trigger the workflow

The user uploads or selects an event brief and runs the agent.

### Step 2: Read event materials

The agent reviews the event brief and any linked or referenced documents to understand logistics, goals, restrictions, and audience details.

### Step 3: Identify key details

It extracts the date, time, venue, rules, expectations for the event, and reasons someone would attend.

### Step 4: Search internal context

The agent scans internal knowledge for relevant insights that may shape tone or framing.

### Step 5: Generate description options

It creates three candidate descriptions with different angles, each including required logistics but written conversationally and without repeating past material.

### Step 6: Select and refine

The agent chooses the strongest draft and rewrites it into a polished, audience-ready event description that includes all essential details and flows naturally.
