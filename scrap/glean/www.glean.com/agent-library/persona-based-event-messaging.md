# Persona-based event messaging

Build persona-specific event messaging grounded in real customer wins and partner insight.

## Overview

The persona-based event messaging agent prepares event and booth teams with clear, consistent messaging tailored to the audience and sponsored event. It reviews existing positioning frameworks, customer stories, and partner materials to craft a concise elevator pitch, top use cases, relevant proof points, and context about the event host. The output is a brief teams can skim before stepping on the floor - helping every conversation feel confident, relevant, and on message.

## See it in action

## Capabilities

-   Highlights the most relevant value propositions for the selected persona to keep conversations focused.
-   Surfaces customer examples with similar industries or challenges to help staff share credible proof points.
-   Reduces prep time by consolidating messaging frameworks, customer wins, and partner information in one place.

## Example output

### Event pitch brief for IT directors at CloudFuture Summit

#### Elevator pitch

Help IT teams reduce operational overhead and resolve issues faster with a unified view of their systems and workflows.

#### Use cases and value for IT directors

-   Centralize logs, metrics, and alerts to speed up troubleshooting
-   Shorten incident response times with accessible runbooks and past timelines
-   Surface risky deployments early to protect reliability
-   Identify unused resources and reduce operational costs  
    

#### Referenceable customers to mention

-   Global retailer reducing investigation time by 40%
-   Mid-market finance firm lowering major incidents by 25%
-   Healthcare provider improving patient portal uptime to 99.95%  
    

#### Partner/event host context

CloudFuture Summit is hosted by Orion Cloud. Many joint customers integrate Orion’s infrastructure data with our workflows. Highlight how this pairing strengthens visibility and accelerates diagnosis for existing Orion users.

## Agent workflow

### Step 1: Trigger input

The user provides a persona and sponsored event name, which informs the research and messaging context.

### Step 2: Gather messaging sources

The agent searches internal messaging documents, persona frameworks, and positioning materials to identify relevant themes.

### Step 3: Analyze persona priorities

It reviews persona-specific challenges, goals, and current trends to determine which value propositions will resonate.

### Step 4: Identify AI and workflow usage

The agent examines how people in this persona currently use technology and where they face friction to inform talking points.

### Step 5: Surface proof points

It searches customer reference materials to find examples from similar industries or use cases and pulls key details into the output.

### Step 6: Retrieve partner and event context

If the event is hosted by a partner, the agent summarizes relevant integrations, joint messaging, or relationship details.

### Step 7: Generate final brief

The agent compiles an elevator pitch, use cases, customer proof points, and partner context into a concise, skimmable event brief.
