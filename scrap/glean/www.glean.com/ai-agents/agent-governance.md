## FAQs

What is Glean Agent Governance?

Glean Agent Governance helps organizations manage AI agents with sharing controls, permission checks, and guardrails, so teams can scale agent use safely.

How does Glean control agent sharing?

Admins can control how broadly agents can be shared. Within those rules, builders can share agents with individuals, teams, or the entire company.

How does Glean protect sensitive data in agents?

Glean enforces permissions for every action an agent takes, so agents only access knowledge the user is authorized to use.

How does Glean keep agents within scope?

Agent alignment models evaluate actions against the agent’s intended purpose and approved behaviors to help keep agents within scope.

Do permission checks happen only once?

No. Agents check permissions on every request, so responses reflect the user’s latest access.

Why does agent governance matter for enterprise AI?

It lets teams build and use agents while giving administrators the controls they need to support safe, enterprise-wide adoption.
