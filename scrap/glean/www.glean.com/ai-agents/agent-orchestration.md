## How agent orchestration works

01

Trigger

Run agents on a schedule. Users can turn on eligible agents and set the times they run.

![](https://cdn.prod.website-files.com/6127a84dfe068e153ef20572/6a8e7f69983e93b11ff23fad_Agent%20Orchestration%20How%20It%20Works%20Connect%20Desktop.png)

02

Route

Define routing rules in the builder so Glean Assistant sends requests to the right specialist agents.

![](https://cdn.prod.website-files.com/6127a84dfe068e153ef20572/6a8e7f6beabb95548dea1084_Agent%20Orchestration%20How%20It%20Works%20Govern%20Desktop.png)

03

Integrate

Launch agents directly inside tools like Slack or ServiceNow, so employees get help without switching context.

## FAQs

What is AI agent orchestration in Glean?

Glean Agent Orchestration connects agents and workflows so tasks can be routed, triggered, and coordinated across systems.

How does Glean trigger agent workflows?

Glean supports time-based triggers, so eligible agents can run on a schedule and handle repeatable work automatically.

How does Glean route work to the right agent?

Routing rules in the builder let Glean Assistant send requests to the right specialist agents for more precise answers and execution.

Can Glean coordinate multiple agents in one workflow?

Yes. Orchestration connects specialized agents and activates each one at the right time, so they can complete multi-step work together.

Can Glean run orchestrated agent experiences inside other tools?

Yes. Agents can launch directly in tools such as Slack or ServiceNow, so employees can get help without switching context.

How do teams improve orchestrated workflows over time?

Teams can refine routing rules and trigger settings as needs change, keeping workflows aligned with real work.
