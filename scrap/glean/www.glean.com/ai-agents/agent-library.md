## FAQs

What is the Glean Agent Library?

The Glean Agent Library is a catalog of AI-powered agents and templates built to automate real business workflows across teams.

What kinds of agents are in the library?

The library includes agents for marketing, sales, support, engineering, HR, IT operations, and company-wide use cases.

Can non-technical users build and use agents?

Yes. Glean supports agent creation in natural language, along with a more powerful builder, so more employees can build and use agents.

How quickly can teams get started with agent use cases?

Teams can start with templates and begin seeing value in days rather than months.

Does the Agent Library respect enterprise permissions?

Yes. Agents are designed to respect organizational permissions and fit the way teams already work.

What are examples of agent templates in Glean?

Examples include agents for SEO article evaluation, turning calls into customer testimonials, prospect outreach emails, support follow-up emails, account snapshots, and engineering standups.
