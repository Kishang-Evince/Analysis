### Overview

Dropbox is a cloud-based platform for storing, syncing, and sharing files across teams. Glean's integration lets users search permissions-enforced folders, files, and Paper docs. Users can also browse folders, search by name or content, extract file text, create files, and generate shared links.

### Features

Glean retrieves context and executes actions across:

-   Team folders and files
-   Private folders and files
-   Dropbox Paper docs
-   File metadata such as name, size, type, and modification date
-   Create folders and text-based files and generate shared links

### Benefits

Search across Dropbox files alongside all your company data to get the full picture of any document. Use Glean to generate new docs grounded in your enterprise context, then save them directly to the right Dropbox folders, so your work lives where your team expects it.
