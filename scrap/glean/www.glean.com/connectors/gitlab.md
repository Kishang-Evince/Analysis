### Overview

Gitlab is a DevOps platform with free open and private repositories that allows people to monitor and complete all tasks in a project. Glean integrates with Gitlab to fetch important files that users may need, such as merge requests. Glean understands all user access permissions and strictly enforces permissions for users at the time of the query, which ensures that users are not able to see results which they do not have access to.

### Features

Glean retrieves context and executes actions across:

-   Merge request descriptions
-   Merge request conversations and comments
-   Commit messages for main branch
-   Wikis
-   Issues
-   Directory and file names
-   Full content of documentation files only (.md and .txt)
-   Repositories

### Benefits

By searching Glean for comments and issues or using the Answers feature, engineering teams can easily find documentation about errors from previous cases to figure out how they can solve a problem with their task.

Customer support teams can find possible solutions for customers by searching Glean and finding documentation on projects that they might not have known about otherwise.
