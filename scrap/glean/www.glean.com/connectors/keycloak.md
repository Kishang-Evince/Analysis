### Overview

Keycloak is an open-source identity and access management solution, providing secure and seamless logins across applications. Glean users authenticate using Keycloak with the OIDC protocol.

### Features

Glean retrieves context and executes actions across:

-   Identity management and application access

### Benefits

Using Keycloak for SSO with Glean provides secure, centralized authentication and seamless access management.
