### Overview

This integration combines Astra DB's powerful database capabilities with Glean's search and indexing features. Developers can transfer data between platforms and query structured data with Glean Chat. The Glean Search component for Langflow unlocks new agentic app workflows. Glean's multi-source aggregated search within DataStax's ecosystem enables more efficient, context-aware GenAI applications.

### Features

Glean retrieves context and executes actions across:

-   Smooth data transfer between Astra DB and Glean
-   Natural language interface for database queries with Glean Chat
-   Enhanced Langflow agentic flows with Glean queries
-   Multi-source aggregated search for rich context

### Benefits

Empower developers with DataStax's AI Platform and Glean's enterprise search. Transfer data between Astra DB and Glean, use natural language for database queries with Glean Chat, and enhance Langflow workflows with Glean's search capabilities.
