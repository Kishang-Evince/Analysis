### Overview

Jumpcloud is a unified identity, device, and access management platform. Glean users authenticate using Jumpcloud with the OIDC protocol.

### Features

Glean retrieves context and executes actions across:

-   Identity management and application access

### Benefits

Using Jumpcloud for SSO simplifies access, enhances security, and scales user management.
