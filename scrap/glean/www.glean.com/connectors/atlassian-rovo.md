### Overview

Atlassian Rovo is AI across Jira and Confluence that helps you accomplish tasks like creating and updating Jira issues and Confluence documents. Glean's integration helps you close the loop on engineering work in Atlassian, right from within Glean.

### Features

Glean retrieves context and executes actions across:

-   Create and update Jira issues including changing statuses and adding comments
-   Create or edit a Confluence page to keep docs up to date

### Benefits

Resolve incidents and close the loop on engineering work by letting Glean create and update Jira and Confluence via Atlassian Rovo.
