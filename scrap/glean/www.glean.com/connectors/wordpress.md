### Overview

WordPress allows you to host and build websites using a plugin architecture and a template system. Using WordPress, you can customize any website to fit your business, blog, portfolio, or online store. Right now, Glean only crawls published WordPress pages, which are publicly accessible, so we don't enforce permissions as part of this integration.

### Features

Glean retrieves context and executes actions across:

-   Pages
-   Posts
-   Comments

### Benefits

Filter through WordPress content quickly based on document type, authors, tags, categories, etc.

Get more context around pages and posts, such as date of publishing, date of last modification, and author or owner name, in one place.
