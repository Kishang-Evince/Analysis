### Overview

Microsoft Outlook is widely used in business environments for email, calendaring, and contact management. Glean lets users search emails, tasks, contacts, and files — and take action directly. Send and forward messages, create calendar invites, update contacts, and pull event details into multi-step workflows without leaving Glean.

### Features

Glean understands and retrieves:

-   Outlook emails and contacts
-   Outlook tasks
-   Files uploaded to Outlook

Glean executes actions across:

-   Send, draft, reply to, and forward emails
-   Create calendar invites and update existing events
-   Create and update contacts
-   Pull message and event details into multi-step workflows

### Benefits

Stay on top of every external conversation tied to your projects, to-dos, and meetings. When scheduling meetings, Glean helps you create calendar events with the right context built in, so every attendee joins ready to collaborate and make decisions.
