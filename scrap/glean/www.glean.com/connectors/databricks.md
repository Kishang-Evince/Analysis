### Overview

The Databricks Platform enables data teams to unify their data, analytics, and AI to power agents, apps, and natural language insights. In Glean, users can query Databricks Genie with natural language, run prepared SQL, and find AI/BI dashboards quickly. In Databricks, Agent Bricks can connect to Glean through MCP so agents can combine structured data with enterprise context from docs, chats, tickets, and more.

### Features

Glean understands and retrieves:

-   Query Databricks Genie in natural language from Glean
-   Run prepared SQL against Databricks in Glean agents
-   Search Databricks AI/BI dashboards directly in Glean
-   Get business context behind Databricks results in one place

Glean executes actions across:

-   Connect Agent Bricks to Glean through MCP
-   Build agents that blend live data with company knowledge
-   Combine Databricks insights with docs, chats, tickets, and wikis
-   Keep access secure and permission-aware across systems

### Benefits

Give business users and builders one secure way to move from question to insight to action by combining Databricks data with the full context behind the numbers.
