### Overview

Gmail powers daily communication across teams and customers. Glean's integration lets users search email history with full enterprise context, then take action - draft and send replies, forward messages, create and apply labels, and move messages to trash. Threads, drafts, contacts, and labels are all accessible from one workflow.

### Features

Glean understands and retrieves:

-   Email content and metadata

‍

Glean executes actions across:

-   Draft, send, reply to, and forward emails
-   Search threads to pull message context into workflows
-   Create and apply labels, and move messages to trash
-   List drafts, labels, contacts, and threads for faster triage

### Benefits

Turn email into actionable context. Search Gmail threads alongside project docs, tickets, and CRM records so you always know where things stand. Then draft replies grounded in what you've been working on, so every message reflects the latest context and keeps things moving.
