### Overview

Airtable is a cloud-based software platform that helps teams organize, plan, and collaborate on work in a more visual and flexible way. Integrating Airtable with Glean enables users to search all Airtable records and comments in real-time. Glean respects all permissions set within Airtable.

### Features

Glean retrieves context and executes actions across:

-   Base text records and comments
-   Real-time updates
-   Authentication data

### Benefits

Enhance team member productivity with real-time, permission-based search across your organization's project content and planning data.
