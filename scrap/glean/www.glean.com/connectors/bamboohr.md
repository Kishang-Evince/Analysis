### Overview

BambooHR enables human resources teams to undertake big picture projects by simplifying operational tasks. Glean’s connection to BambooHR can fetch relevant people information via an API token in BambooHR. It’s important to note that all data is stored in the GCP project in your cloud account, and no data leaves your environment. In addition, Glean does not record any sensitive information, such as salary data.

### Features

Glean retrieves context and executes actions across:

-   Employee name
-   Title
-   Department
-   Manager email
-   Join date
-   Phone number

### Benefits

Automate and complete HR tasks faster by being able to search for all HR-related company files, across all platforms used.

Employees can find the people they need to work with, regardless of department, using Glean’s Directory feature, which provides BambooHR information and other profile details.
