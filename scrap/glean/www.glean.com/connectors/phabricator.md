### Overview

Phabricator provides collaborative web-based software development tools, including a code review tool, a repository browser, a change monitoring tool, a bug tracker, and a wiki. Connecting to Phabricator enables Glean users to search past activity with each of these tools.

### Features

Glean retrieves context and executes actions across:

-   Code from the repository and code review tool
-   Logs from the Phabricator bug tracker
-   Content from the Phabricator wiki

### Benefits

Surface your historical activity from across Phabricator's web development platform.
