### Overview

Backstage is an open-source platform for building developer portals that organize and centralize tooling, software components, data, and documentation. Connecting Glean to Backstage gives users permissions-based access to search your entire developer ecosystem, enhancing collaboration and improving collective knowledge.

### Features

Glean retrieves context and executes actions across:

-   Service catalog
-   Website deployment
-   Service documentation
-   API Library documentation

### Benefits

Enable developer workflows with deep visibility into the developer ecosystem. Search your entire service catalog, deployments, and all of your documentation for easy understanding of workflows.
