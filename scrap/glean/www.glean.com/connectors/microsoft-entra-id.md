### Overview

Microsoft Entra ID (formerly known as Azure Active Directory) is a cloud-based identity and access management service that enables secure access to applications using company credentials. This integration ensures that only authorized users can access Glean, enhancing overall security. Glean users authenticate using Entra with the OIDC protocol.

### Features

Glean retrieves context and executes actions across:

-   Identity management and application access

### Benefits

Microsoft Entra Single sign-on (SSO) with Glean enhances security and streamlines user management.
