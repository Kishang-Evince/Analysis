### Overview

Bitbucket is a Git-based code hosting and collaboration tool for teams. Right now, Glean connects to Bitbucket Cloud and only accesses repositories within your Bitbucket account. User and group access controls are enforced on a repository level.

### Features

Glean retrieves context and executes actions across:

-   Pull Requests, including comments inlined on pull request documents
-   Markdown content
-   Text file content
-   File and Directory names

### Benefits

Past projects are in one place and quickly accessible using Glean’s powerful search capabilities, which allow users to be more productive and solve problems faster.

Users can see which Bitbucket files are trending on their teams and track prevalent issues or popular projects.
