### Overview

Glean connects to Snowflake, the AI Data Cloud, in multiple ways: through Glean Assistant for text-to-SQL insights, through Glean Agents and Snowflake agents to execute governed, trusted workflows with full enterprise context, through Snowflake Intelligence via MCP, and through Cortex Code for developer workflows. The result is governed, permission-aware insights enriched with docs, conversations, tickets, and workflows across the business.

### Features

Glean understands and retrieves:

-   Ask Snowflake questions in natural language to get insights grounded in enterprise context
-   Combine Snowflake data with docs, chats, tickets, and workflows
-   Use Glean Agents and Snowflake Cortex Agents to orchestrate next steps

Glean executes actions across:

-   Bring Glean context into Snowflake Intelligence via MCP
-   Extend developer workflows with Glean in Snowflake Cortex Code
-   Keep answers secure and permission-aware based on existing access controls
-   Turn governed insights into automations, visualizations, and shareable outputs

### Benefits

Give business users, data teams, IT leaders, and builders one secure place to access governed data, add enterprise context, and move from insight to action faster.
