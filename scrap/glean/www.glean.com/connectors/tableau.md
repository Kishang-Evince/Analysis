### Overview

Glean connects seamlessly with your Tableau instance to fetch relevant information that feeds directly into Glean’s enterprise search software. Glean’s Tableau integration understands all user access permissions and strictly enforces them at the time of the query, which ensures that users are not able to see content they do not have access to. Most importantly, all data is stored in a GCP project inside your cloud account, and no data leaves your environment.

### Features

Glean retrieves context and executes actions across:

-   Workbooks
-   Data sources

### Benefits

**Resolve customer cases faster by finding the most relevant Tableau content using Glean’s powerful search capabilities.**‍

You can see more context around Tableau content, including how popular it is, who has accessed it, when it was last accessed, etc.
