### Overview

Box is a cloud-based platform for businesses’ content management, collaboration, and file sharing tools. Connecting Box with Glean allows Glean to fetch relevant content from Box. Glean understands all user access permissions and strictly enforces permissions for users at the time of the query, which ensures that users are not able to see results which they do not have access to. Also, all data is stored in a GCP project inside your cloud account, and no data leaves your environment.

### Features

Glean retrieves context and executes actions across:

-   Folders
-   Documents
-   Box Notes

### Benefits

Never lose track of documents again by using any relevant words to search through and find content on Box in folders, notes, and documents. Glean’s Go Links feature, which enables users to create short and memorable links, gives quicker and easier access to Box files.
