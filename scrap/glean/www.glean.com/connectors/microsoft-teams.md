### Overview

Microsoft Teams is a workspace for chat, video conferencing, file storage, and application integration. Glean's integration lets users search public conversations and shared files with permissions strictly enforced. Teams can also send messages, create group chats, post to channels, and add members - bringing communication and action into one workflow.

### Features

Glean understands and retrieves:

-   Conversations in public channels
-   Files shared in public channels
-   Chat messages

Glean executes actions across:

-   Create group chats
-   Send direct messages in chats
-   Post messages to channels
-   Create channels and add members to teams

### Benefits

Find relevant conversations in public channels and files shared in public channels easily and quickly using Glean’s powerful search capabilities.
