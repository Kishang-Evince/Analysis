### Overview

Azure DevOps is a set of development tools by Microsoft that support the entire software development lifecycle. Engineering organizations often use Azure Wikis for documentation and project management. With this connector, allows users to search and query Azure Wikis directly within Glean.

### Features

Glean retrieves context and executes actions across:

-   Project wikis
-   Code wikis

### Benefits

Azure DevOps captures relevant documentation that provides context into engineering projects and code. By pairing the wiki information with context found in communication tools and the codebase, Glean provides a comprehensive view into engineering work whether that be a new feature, bug, or issue. Now, your engineering team can get the context they need to code faster from a single source of truth, Glean.
