## Draft a usability testing script

## prompt

Generate a comprehensive usability testing script for the following \[\[Product Requirements Doc URL\]\]:Introduction:- Provide a brief overview of the purpose of the usability test.- Explain the feature being tested.- Outline the structure of the session, including the tasks and follow-up questions.- Reassure the participant that the focus is on the product, not their performance.Tasks:- List the specific tasks the participant needs to complete.- Ensure each task is clear and concise.- Include any necessary context or background information for each task.- Specify any tools or resources the participant will need to use.Follow-Up Questions:- Prepare a set of questions to ask after each task to gather feedback on the participant's experience.- Include questions to understand the participant's thought process, any difficulties encountered, and suggestions for improvement.- Add questions to gauge the participant's overall satisfaction with the feature.
