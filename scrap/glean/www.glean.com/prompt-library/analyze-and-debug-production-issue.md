## Analyze and debug production issue

## prompt

Analyze and debug a production issue: 1. Read \[\[Issue\]\]2. Search: Find relevant documents related to the error and possible playbooks.3. Think: From the list of possible playbooks, select ONE playbook that can most likely help resolve the error.4. Search: Based on error message, search for tickets with the same issue.5. Respond: Provide 3 similar past issues. Provide steps on how to resolve the issue from the selected playbook. Provide the names and emails of up to 3 experts to help resolve the issue.
