## Creating Agendas for a Customer Meeting

## prompt

Create an agenda for my call with \[\[Account name\]\] . Please include any new features that have launched in the past month or will launch in the next two weeks. Make sure it is a bulleted list and add an emoji to the start of each bullet that correlates to the agenda item. Also include any open betas we have. Be sure to only use sources that mention the customer for the follow up section. Assume we don't need to do introductions for these meetings. For each new feature or beta feature, provide a 1 sentence overview and hyperlink the external facing documentation. Do not use the same emojis for any other bulletpoints. Only use documentation that has the \[External\] title when you hyperlink.
