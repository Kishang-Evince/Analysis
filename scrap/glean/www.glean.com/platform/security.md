## Built-in AI security, enforced end-to-end

**Always-on auditing.** Every control point is logged to an end-to-end audit trail as it happens, with events available to stream into SIEM.

01

Identity & access

Verify who is making the request via your SSO provider before AI runs, including both user and agent identity.

![](https://cdn.prod.website-files.com/6127a84dfe068e153ef20572/6a8e63f82da676b3c7066978_Security%20accordian%20img.png)

02

Data permissions

Enforce source-system permissions on every read and write; an agent should not automatically access everything the user can.

![](https://cdn.prod.website-files.com/6127a84dfe068e153ef20572/6a8e63f82da676b3c7066978_Security%20accordian%20img.png)

03

Sensitive content protection

Detects and blocks sensitive content for both structured and unstructured data across apps.

![](https://cdn.prod.website-files.com/6127a84dfe068e153ef20572/6a8e63f82da676b3c7066978_Security%20accordian%20img.png)

04

Topic restrictions

Check requests against acceptable use and industry-specific policies before the model responds.

![](https://cdn.prod.website-files.com/6127a84dfe068e153ef20572/6a8e63f82da676b3c7066978_Security%20accordian%20img.png)

05

Runtime threat protection

Screen for prompt injection, malicious code, and harmful content while AI operates.

![](https://cdn.prod.website-files.com/6127a84dfe068e153ef20572/6a8e63f82da676b3c7066978_Security%20accordian%20img.png)

06

Action alignment

Check agent actions against the user’s intent and authority before execution.
