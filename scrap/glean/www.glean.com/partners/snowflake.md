## Get governed insights faster with Glean and Snowflake Integrations

## Query Snowflake directly in Glean Assistant

Instead of navigating dashboards or writing SQL, users can ask Glean Assistant business questions in plain English and get governed answers from live Snowflake data in seconds.

## Automate data analysis with Glean Agents and Snowflake Cortex Agents

Glean Agents can bring Snowflake data directly into multi-step execution and automated workflows. Instead of manually creating reports and dashboards, data teams and business users can create agents that provide automated self-serve analytics and reports.

## Query Snowflake Intelligence with Glean MCP

Users working inside Snowflake can leverage Glean to pull in relevant company context, past decisions, docs, and process knowledge alongside structured data analysis. 

## Integrate Snowflake Cortex Code with Glean MCP

Users can leverage Glean to connect enterprise data to build Snowflake Semantic Views with Snowflake Cortex Code.
