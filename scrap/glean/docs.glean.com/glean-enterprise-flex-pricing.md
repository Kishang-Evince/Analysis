On this page

Glean Enterprise Flex, Glean's new pricing model, delivers both predictability and flexibility for your organization. With Enterprise Flex you get the simple budgeting of a per-user license, combined with a pooled allowance of pay-per-use credits when your organization extensively uses advanced Al features. Glean includes a pool of credits as part of the per-user licenses and you only pay when you go above the initial allocation.

## FlexCredits[​](#flexcredits "Direct link to FlexCredits")

FlexCredits unlock advanced, pay-per-use capabilities for every user on the Glean Platform. FlexCredits are shared and pooled at the organizational level, and make it simple for users to access advanced features and additional consumption beyond included seat capabilities.

Enterprise Flex Agreements always include a generous base pool of FlexCredits for the organization, so every user can make daily use of advanced capabilities. Additional FlexCredits can be added at any time as needed by purchasing additional FlexCredit Packs.

Metered capabilities on the Glean Platform consume FlexCredits at runtime, on either a fixed basis per run, or on a variable basis depending upon the complexity of the AI task. FlexCredit consumption per capability is outlined in the Rate Card below.

FlexCredits are a measure of the complexity of the tasks Glean performs for each query, capability, or Agent run, and vary depending on the complexity of agentic task planning, understanding, and orchestration; data indexed, searched, and retrieved; quality, evals, security, and governance analysis and enforcements; response synthesis; tools used and actions taken in connected applications; as well as underlying compute and LLM infrastructure used. Because delivering Assistant responses and Glean Agent outcomes exercise the entire Glean Platform, FlexCredits pay for the usage of the entire platform’s capabilities to deliver the AI outcomes at hand.

Infrastructure costs are a minor portion of a FlexCredit’s total value, however FlexCredits are discounted for customers who choose to supply their own LLM keys and/or self-host Glean in their private cloud instance to compensate for compute and model infrastructure costs the customer bears.

### Model Tiers[​](#model-tiers "Direct link to Model Tiers")

We provide a wide range of models for Glean Assistant and Glean Agents that are categorized into Basic, Standard, and Premium based on their reasoning capabilities and overall cost to run.

For Glean Assistant the use of Basic and Standard models in fast mode are included in Enterprise Flex Seats, while using Premium models incurs FlexCredits. When using Glean's auto model selector, Glean will select the right model for a given task, balancing reasoning capabilities, cost efficiency, and reliability. When Premium models are auto selected, FlexCredits will be consumed. All Premium models can be disabled in the admin console.

For Glean Agents, each agent run uses a variable number of FlexCredits, determined by the complexity of an agent including how many connectors it searches, how many steps it takes, how much memory it maintains, how many tools it executes, and the model used for each step. Agents that use higher-tiered models will consume more FlexCredits than agents that use lower-tiered models.

## Legacy Glean Enterprise customers[​](#legacy-glean-enterprise-customers "Direct link to Legacy Glean Enterprise customers")

In addition to the features included in Glean Enterprise, at Glean's discretion, you will have access to the following Enterprise Flex capabilities through the length of your current term at which point, you will need to move entirely to Glean Enterprise Flex.

These capabilities were launched as part of Glean Enterprise Flex, are not included in Glean Enterprise, and are provided solely at Glean's discretion. At the point that you move to Glean Enterprise Flex, you will receive an allocation of base credits as part of your Enterprise Flex Seat. Any balance of FlexCredits provided by Glean prior to your Enterprise Flex upgrade does not entitle you to these features.
