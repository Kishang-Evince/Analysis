## Issue[​](#issue "Direct link to Issue")

Glean isn't able to generate a user access token using the credentials provided for the GitHub App.

## Resolution[​](#resolution "Direct link to Resolution")

Ensure that your GitHub App credentials, including the client ID and client secret, are valid.

For additional assistance, contact [Glean Support](https://support.glean.com).
