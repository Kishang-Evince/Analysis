## Issue[​](#issue "Direct link to Issue")

The provided account url isn't in the right format.

## Resolution[​](#resolution "Direct link to Resolution")

Please follow the setup instructions and make sure that you copy full account url from your databricks account home page which also has the **account\_id** parameter set in it.

If you are still having difficulty please reach out to us: [https://support.glean.com](https://support.glean.com)
