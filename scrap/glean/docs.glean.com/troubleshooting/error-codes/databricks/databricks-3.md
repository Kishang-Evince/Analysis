## Issue[​](#issue "Direct link to Issue")

We are unable to fetch users from databricks workspaces.

## Resolution[​](#resolution "Direct link to Resolution")

-   Please ensure you have provided Glean's IP Address access to your workspaces in case IP restrictions are in place.
-   Ensure that we have at least one workspace left to crawl after applying red or green list configs.
-   If you are using Azure Databricks or non account admin mode make sure all the provided workspaces have correct information.

If you are still having difficulty please reach out to us: [https://support.glean.com](https://support.glean.com)
