Custom connector name config is not lowercase and alphanumeric

Please ensure that the custom connector name config consists of lowercase alphabets and decimal digits only. For example web2qs9yszgleanhelp is a valid custom connector name

For additional assistance, please contact Glean Support at [https://support.glean.com](https://support.glean.com)
