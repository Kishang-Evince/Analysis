## Issue:[​](#issue "Direct link to Issue:")

-   The Glean Jira Activity plugin is not installed on your Jira Cloud instance. The Activity plugin is important for providing the best Glean experience.

## Resolution:[​](#resolution "Direct link to Resolution:")

-   For Jira Cloud, please follow the setup to install the Activity plugin on your Jira Cloud instance.

For additional assistance, please contact Glean Support at [https://support.glean.com](https://support.glean.com)
