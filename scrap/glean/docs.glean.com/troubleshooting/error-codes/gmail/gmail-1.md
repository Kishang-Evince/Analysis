## Issue[​](#issue "Direct link to Issue")

Could not find an associated active Google Drive instance

## Resolution[​](#resolution "Direct link to Resolution")

-   Gmail uses user data and credentials from an associated Google Drive app. Make sure you have selected a valid Google Drive app on the setup page.
-   If you haven't set up a Google Drive app yet, do that first.
