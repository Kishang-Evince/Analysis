## Possible errors[​](#possible-errors "Direct link to Possible errors")

-   Invalid Dynamics 365 organization ID provided.
-   Unable to connect to the specified Dynamics 365 organization.

## Possible reasons[​](#possible-reasons "Direct link to Possible reasons")

-   Typo in the organization ID.
-   Organization is disabled or moved.
-   Network connectivity issues or firewall restrictions.
-   Attempting to connect to a trial environment that is expired.

## Possible resolution[​](#possible-resolution "Direct link to Possible resolution")

To resolve this error, try the following resolution:

### Getting Dynamics 365 Organization ID[​](#getting-dynamics-365-organization-id "Direct link to Getting Dynamics 365 Organization ID")

For more information on getting the organizational ID, see [Get Dynamics 365 Organization ID](/connectors/native/microsoft/microsoft-dynamics-365-connector#6-get-dynamics-365-organization-id) .
