**Issue**

-   The discovery token for Slack Enterprise Grid does not have necessary scopes

**Resolution**

-   Check the discovery token has been created and authenticated for Slack Enterprise Grid. Please make sure the token has **discovery:read** as one of the scopes. If you are still having difficulty please reach out to us: [https://support.glean.com](https://support.glean.com).
