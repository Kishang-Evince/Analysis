**Issue**

-   We made an API call to the Slack discovery APIs and the API returns a non successful response.

**Resolution**

-   Please ensure that the Discovery API has been enabled for your Slack Enterprise. If you are still having difficulty please reach out to us: [https://support.glean.com](https://support.glean.com).
