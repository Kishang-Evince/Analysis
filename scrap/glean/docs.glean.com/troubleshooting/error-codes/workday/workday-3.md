## Issue:[​](#issue "Direct link to Issue:")

The integration system security group does not have GET access to the Worker Data: Public Worker Reports domain.

## Resolution:[​](#resolution "Direct link to Resolution:")

Follow the instructions during setup to grant the right permissions to the security group.
