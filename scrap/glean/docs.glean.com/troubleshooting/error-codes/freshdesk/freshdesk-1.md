## Issue[​](#issue "Direct link to Issue")

-   Glean is lacking admin access to the Freshdesk instance.

## Resolution[​](#resolution "Direct link to Resolution")

-   Ensure the agent providing the API key has a role with the "Admin → Play God with Super Admin controls" permission.
-   For more details on permissions, refer to the Freshdesk setup instructions.

For additional assistance, please contact Glean Support at [https://support.glean.com](https://support.glean.com)
