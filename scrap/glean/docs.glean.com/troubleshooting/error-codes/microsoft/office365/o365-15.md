## Issue:[​](#issue "Direct link to Issue:")

-   The SharePoint domain format is invalid. This error occurs when:
    -   No SharePoint domains are configured
    -   Domain doesn't end with `.sharepoint.com`
    -   Domain contains invalid characters (only alphanumeric, dots, and hyphens are allowed)
    -   Domain is a OneDrive URL (contains `-my` subdomain)
    -   Domain includes protocol prefix like `https://`

## Resolution:[​](#resolution "Direct link to Resolution:")

-   Ensure all SharePoint domains:
    -   End with `.sharepoint.com`
    -   Only contain alphanumeric characters, dots, and hyphens
    -   Do not include OneDrive URLs (e.g., `tenant-my.sharepoint.com`)
    -   Do not include protocol prefixes (e.g., `https://`)
    -   Example of valid domain: `contoso.sharepoint.com`
-   If you need help configuring SharePoint domains, please contact Glean Support at [https://support.glean.com](https://support.glean.com).
