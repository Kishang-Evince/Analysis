## Issue:[​](#issue "Direct link to Issue:")

-   Glean is unable to fetch user segments. This is most likely caused due to invalid authentication credentials.

## Resolution:[​](#resolution "Direct link to Resolution:")

-   Confirm that the API access token entered on the admin console is correct.
