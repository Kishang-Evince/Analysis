## Issue[​](#issue "Direct link to Issue")

Glean is unable to validate that the provided access token has owner access to the top-level group.

## Resolution[​](#resolution "Direct link to Resolution")

Make sure that the access token has owner permissions on the top-level group.

If the problem persists, contact [Glean Support](https://support.glean.com).
