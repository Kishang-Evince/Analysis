## Issue[​](#issue "Direct link to Issue")

-   The API key provided for the Granola connector is invalid, expired, or missing.
-   This error occurs when Glean attempts to verify the API key by calling the Granola API and receives an authentication failure or connection error.

## Resolution[​](#resolution "Direct link to Resolution")

-   Verify that you have entered a valid Granola Enterprise API key.
-   Ensure the API key has not expired or been revoked.
-   Confirm that the API key was generated by a workspace admin with appropriate permissions.
-   If using a Personal API key, ensure it has been enabled by the workspace admin (Enterprise plans require the admin to enable the personal key toggle).
-   In the Glean Admin console, go to **Connectors** > **Add connector** > **Granola**, paste the new API key into the **API Key** field, and click **Save & Verify**.

For additional help, contact [Glean Support](https://support.glean.com).
