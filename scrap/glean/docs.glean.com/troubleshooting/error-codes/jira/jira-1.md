## Issue:[​](#issue "Direct link to Issue:")

-   The Base URL entered is in an incorrect format. The Base URL should not be empty and should not end with a "/" (slash). Some examples of a valid base URL are `https://domain1.com`, `https://domain1.com/jira`

## Resolution:[​](#resolution "Direct link to Resolution:")

-   Please enter the Base URL in the correct format
