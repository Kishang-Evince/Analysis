## Issue:[​](#issue "Direct link to Issue:")

-   The configuration value you entered did not pass validation. This may be due to missing required fields, an incorrect format, or an invalid token.

## Resolution:[​](#resolution "Direct link to Resolution:")

-   Please make sure that all required fields on the setup page are completed and that each value is entered in the correct format.

If you are still having difficulty please reach out to us: [https://support.glean.com](https://support.glean.com)
