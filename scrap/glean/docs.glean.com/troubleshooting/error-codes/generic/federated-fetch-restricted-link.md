## Issue[​](#issue "Direct link to Issue")

This error means that a federated fetch request was blocked because Glean determined the link is restricted.

## Resolution[​](#resolution "Direct link to Resolution")

Check the source application's visibility or access settings and any restrictions configured for that connector in Glean. If the issue persists, contact your Glean administrator or [Glean Support](https://support.glean.com).
