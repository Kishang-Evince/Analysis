## Issue[​](#issue "Direct link to Issue")

The identity provider's authorization server encountered an unexpected internal error or is temporarily unavailable. This is not caused by Glean's configuration.

## Resolution[​](#resolution "Direct link to Resolution")

1.  Wait a few minutes and retry the OAuth flow from the Glean Admin Console.
2.  Check the identity provider's status page for any ongoing outages or maintenance.
3.  If the error persists after the provider confirms no outage, contact [Glean Support](https://support.glean.com) with the timestamps of the failed attempts.

For additional assistance, contact [Glean Support](https://support.glean.com).
