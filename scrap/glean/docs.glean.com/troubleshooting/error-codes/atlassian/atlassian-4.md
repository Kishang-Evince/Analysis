## Issue:[​](#issue "Direct link to Issue:")

-   The Glean Forge crawler app is not installed in your Confluence / Jira instance.

## Resolution:[​](#resolution "Direct link to Resolution:")

-   Please use the Glean Forge crawler app installation link in the Glean admin setup page to install the app into your Confluence / Jira instance.

If you are still having difficulty please reach out to us: [https://support.glean.com](https://support.glean.com)
