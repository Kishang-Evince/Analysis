## Issue[​](#issue "Direct link to Issue")

The Workfront admin user does not have sufficient permissions to access event subscriptions. Glean requires access to the Event Subscription API to receive real-time updates from Workfront.

## Resolution[​](#resolution "Direct link to Resolution")

Ensure the admin user specified during setup has **System Administrator** access level in Workfront. System Administrator access is required to create and manage event subscriptions.

For additional assistance, contact [Glean Support](https://support.glean.com).
