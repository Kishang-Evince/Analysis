## Issue[​](#issue "Direct link to Issue")

We are unable to validate if webhooks are configured for Glean in your Confluence Datacenter instance.

## Resolution:[​](#resolution "Direct link to Resolution:")

For Confluence Datacenter, if you are using a non-Admin privileged service account, please follow the [setup instructions](/connectors/native/confluence-onprem/#3b-connect-the-webhook) to configure webhooks manually.

If you are still having difficulty, please reach out to us: [https://support.glean.com](https://support.glean.com)
