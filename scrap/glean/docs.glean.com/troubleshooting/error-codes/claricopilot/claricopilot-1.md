## Issue[​](#issue "Direct link to Issue")

-   Failed to access the Salesloft Conversation Intelligence API using the provided credentials.

## Possible reasons[​](#possible-reasons "Direct link to Possible reasons")

-   The API Key is incorrect or has been revoked.
-   The API Password is incorrect.

## Resolution[​](#resolution "Direct link to Resolution")

To resolve this error, try one or more of the following resolutions:

### Verify your API credentials[​](#verify-your-api-credentials "Direct link to Verify your API credentials")

Confirm that the API Key and API Password entered in Glean match the credentials in your Salesloft Conversation Intelligence account settings.

### Generate new credentials[​](#generate-new-credentials "Direct link to Generate new credentials")

If your credentials have been rotated or revoked, generate a new API Key and API Password from the Salesloft Conversation Intelligence admin console and update them in Glean.

### Verify API access[​](#verify-api-access "Direct link to Verify API access")

Ensure that your Salesloft Conversation Intelligence account has API access enabled and that the credentials have permission to access user data.

For additional assistance, please contact Glean Support at [https://support.glean.com](https://support.glean.com)
