## Issue[​](#issue "Direct link to Issue")

-   The API key validation failed when connecting to Crayon. This can occur when:
    -   The API key is invalid or has been revoked
    -   The Crayon API is temporarily unreachable

## Resolution[​](#resolution "Direct link to Resolution")

To resolve this error, try the following:

-   **Invalid API key**: Verify that your Crayon API key is correct and has not been revoked. API keys can only be generated by users with the **Admin** or **Integrator** role in Crayon. To generate a new key:
    
    1.  Log in to Crayon at `https://app.crayon.co/login/`
    2.  Navigate to **Admin** → **API Keys**
    3.  Click **Create New API Key**
    4.  Copy the generated key and paste it into the Glean admin console
-   **Failed to connect to Crayon**: This is likely a temporary connectivity issue. Retry in a few minutes and verify that the Crayon instance is accessible.
    

If you continue to see this error, contact [Glean Support](https://support.glean.com/hc/en-us).
