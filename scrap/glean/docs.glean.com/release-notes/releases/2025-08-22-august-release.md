#### Performance improvements[​](#performance-improvements "Direct link to Performance improvements")

Significant performance improvements have been made to search and indexing. Users will experience faster load times and more responsive interactions.

**How to access:** Available automatically to all users.

[Learn more](/user-guide/search/how-to-search-in-glean)

#### New integrations[​](#new-integrations "Direct link to New integrations")

Glean now integrates with popular productivity tools including Slack, Microsoft Teams, and Google Workspace. Users can access Glean directly from these platforms.

**How to access:** Go to Settings → Integrations to connect your accounts.

[Learn more](/connectors/)

Integrations *ROAD-667*

## Admin Features[​](#admin-features "Direct link to Admin Features")

#### User management enhancements[​](#user-management-enhancements "Direct link to User management enhancements")

The user management interface has been redesigned with better search, filtering, and bulk operations. Admins can now manage users more efficiently.

**How to access:** Navigate to Admin Console → Users.

[Learn more](/administration/identity/roles/manage-users)

User Management *ROAD-634*
