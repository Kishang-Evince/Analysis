## User Features[​](#user-features "Direct link to User Features")

#### Dark mode support[​](#dark-mode-support "Direct link to Dark mode support")

Glean now supports dark mode across all platforms. Users can switch between light and dark themes in their preferences.

**How to access:** Go to Settings → Appearance → Theme to enable dark mode.

[Learn more](/user-guide/advanced/customizing-home-page)

#### Keyboard shortcuts[​](#keyboard-shortcuts "Direct link to Keyboard shortcuts")

New keyboard shortcuts have been added to improve productivity. Users can navigate and perform actions more quickly using keyboard commands.

**How to access:** Press `?` in the application to view all available shortcuts.

[Learn more](/user-guide/search/how-to-search-in-glean)

## Admin Features[​](#admin-features "Direct link to Admin Features")

#### Data export improvements[​](#data-export-improvements "Direct link to Data export improvements")

Admins can now export data in multiple formats including CSV, JSON, and Excel. Export options include filtering and custom date ranges.

**How to access:** Navigate to Admin Console → Data → Export.

[Learn more](/administration/insights/overview)
