The Confluence tools let you search, retrieve, and work with your Confluence spaces, pages, and content directly from Glean. Each tool includes a brief description, its parameters, and example usage so you can understand when and how to use it. You can use these tools while configuring agents or workflows that rely on Confluence data.

The following are the supported Confluence tools that you can use to create workflows. These tools are available for both Glean Agents and Glean Assistant.

[

### Get spaces

Retrieves a paginated list of spaces from your Confluence instance







](/tools/connector/confluence/get-spaces)[

### Get pages

Retrieves a paginated list of Confluence pages with optional filtering







](/tools/connector/confluence/get-pages)[

### Get child pages

Lists all direct child pages of a given Confluence page







](/tools/connector/confluence/get-child-pages)[

### Create page

Creates a new Confluence page in a specified space







](/tools/connector/confluence/create-page)[

### Update page

Updates an existing Confluence page’s content and related metadata







](/tools/connector/confluence/update-page)[

### Create blog post

Creates a new Confluence blog post in a specified space







](/tools/connector/confluence/create-blogpost)[

### Update blog post

Updates an existing Confluence blog post’s title or body







](/tools/connector/confluence/update-blogpost)[

### Search content

Finds Confluence pages using intelligent ranking based on how well page titles match the search query







](/tools/connector/confluence/search-content)[

### Get current user

Returns details about the currently authenticated Confluence account to confirm user identity and permissions







](/tools/connector/confluence/get-current-user)[

### Get page by ID

Returns a Confluence page by its ID







](/tools/connector/confluence/get-page-by-id)[

### Create space

Creates a new Confluence space for teams, projects, or knowledge domains







](/tools/connector/confluence/create-space)[

### Get blog posts

Lists blog posts available to the connected Confluence account with pagination support







](/tools/connector/confluence/get-blogpost)[

### Add content label

Adds metadata labels to existing Confluence pages or blog posts







](/tools/connector/confluence/add-content-label)
