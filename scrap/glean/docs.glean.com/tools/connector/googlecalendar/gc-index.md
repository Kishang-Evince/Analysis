You can use Google Calendar tools with Glean agents to read and manage calendar data. Use these tools to search for events, check availability, and create, update, or cancel calendar entries directly from an agent. These tools are available for both Glean Agents and Glean Assistant.

[

### Find free slots

Find free and busy time slots in Google Calendar for one or more calendars over a time range







](/tools/connector/googlecalendar/gc-find-free-slots)[

### Create event

Create a new event in a connected Google Calendar







](/tools/connector/googlecalendar/create-event)[

### Find event

Search for events in a Google Calendar using text, date ranges, and event types







](/tools/connector/googlecalendar/find-event)[

### List events

Retrieves events from a specific Google Calendar with support for filters such as time range, event types, and search terms







](/tools/connector/googlecalendar/list-events)[

### Patch event

Update an existing Google Calendar event by changing specific fields







](/tools/connector/googlecalendar/patch-event)[

### Delete event

Delete an existing event from a connected Google Calendar







](/tools/connector/googlecalendar/delete-event)[

### List Google calendars

Retrieve a list of calendars available in a user's Google Calendar account for browsing or selection before creating or updating events.







](/tools/connector/googlecalendar/list-google-calendars)[

### Remove attendee from event

Remove a single attendee from an existing Google Calendar event by updating the event's guest list







](/tools/connector/googlecalendar/remove-attendee-from-event)
