Use Snowflake tools with Glean agents or assistant to query Snowflake data using SQL or natural language. Choose between direct SQL control or Cortex Analyst and Cortex Agent workflows, then compose results with downstream steps.

[

### Search Snowflake with SQL

Run read-only SQL queries against Snowflake and return tabular results







](/tools/connector/snowflake/search-snowflake-with-sql)[

### Search Snowflake with Cortex

Query Snowflake with Cortex Analyst using natural language







](/tools/connector/snowflake/search-snowflake-with-cortex)[

### Snowflake Cortex Agent tool

Send a natural language query to a pre-configured Cortex Agent and return its response







](/tools/connector/snowflake/query-snowflake-cortex-agent)

note

When not everyone in your organization has a Snowflake account, you can run agents on a shared [service credential](/administration/agent-identity/snowflake) so they query Snowflake through an admin-scoped service identity instead of each user's account.
