On this page

The People Profile Search tool is designed to facilitate searches for internal employee profiles. This tool helps users retrieve detailed profile information about colleagues, including job titles, departments, contact information, and other relevant attributes.

## Usage examples[​](#usage-examples "Direct link to Usage examples")

1.  **Employee Lookup**: The People Profile Search tool can be used to review a list of people who contributed to a project and return up-to-date contact information for follow-up questions.

## Configuration[​](#configuration "Direct link to Configuration")

1.  Select the **Chat** icon from the left-hand navigation.
2.  Select **Agents** from the left-hand navigation.
3.  Select the **People Profile Search** tool from the list of available tools.
4.  Provide manual or AI-generated instructions (e.g., “Find the contact information of the project managers listed in the above steps”).
    -   Specify the search queries or criteria that the tool will use to filter profiles. This could include attributes like name, department, job title, or location.
    -   Example query: `"find employees in [[department]] department"`.
    -   Examples:
        -   alex mercer
        -   security engineering location:"palo alto"

Test the tool to ensure it retrieves and displays the intended profile information accurately.
