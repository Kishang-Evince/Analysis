On this page

The Glean Web Search tool conducts web searches to retrieve relevant information from the internet.

## Usage examples[​](#usage-examples "Direct link to Usage examples")

-   **Meeting Preparation**: Prepare for a meeting using the Web Search tool to gather recent news about a prospect or company. Combine web search results with data found in your enterprise, from sources including docs, chat, CRM, and meeting transcription.
-   **Competitive Analysis**: Track industry trends and competitor activities by leveraging web searches to find the latest data.

## Configuration[​](#configuration "Direct link to Configuration")

Configure the Web Search tool by entering search queries in one of two ways:

-   Define fixed queries manually
    -   Use this method to provide your exact queries to the web search engine. Examples:
        -   AT&T board of directors
        -   Tesla latest news
-   Write a plain text prompt for Glean to generate queries from. Glean uses this plain text field to generate queries, which it passes to Glean Search.
