On this page

You can delete the Microsoft tool pack or control where individual Microsoft tools are available.

## Delete the Microsoft tool pack[​](#delete-the-microsoft-tool-pack "Direct link to Delete the Microsoft tool pack")

1.  Navigate to **Admin console → Platform → Tools**.
2.  Select the Microsoft tool pack.
3.  Click **More → Delete**.

Deleting the pack removes its tools from Glean.

## Limit Microsoft tool availability[​](#limit-microsoft-tool-availability "Direct link to Limit Microsoft tool availability")

1.  Navigate to **Admin console → Platform → Tools**.
2.  Select the Microsoft tool pack, then open **Configuration**.
3.  Under **Enable tools**, click **Edit settings**.
4.  Expand the section for the place where you want to control access.
5.  Set **Access** for each tool. Select all teammates, limit access to specific teammates or departments, or clear the selection to make the tool unavailable in that section.
6.  Click **Save**.
