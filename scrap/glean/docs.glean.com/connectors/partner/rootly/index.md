On this page

Glean is proud to partner with Rootly to provide a seamless experience for your team. Refer the [Rootly documentation](https://docs.rootly.com/integrations/glean) or contact their support team with any questions.

AI-powered on-call and incident response. Trusted by leading companies like NVIDIA, Squarespace, Canva, Figma, and more. The Rootly connector lets Glean users quickly access incidents, alerts, reports, schedules, and escalation policies, enabling faster resolution, trend discovery, and easier reporting.

## Features[​](#features "Direct link to Features")

-   **Search incidents & retros:** Instantly surface Rootly timelines, RCAs, SEVs, and other response data directly in Glean.
    
-   **Track action items:** Expose Rootly postmortem tasks and follow-ups across systems for better accountability.
    

## Benefits[​](#benefits "Direct link to Benefits")

Bring Rootly’s incident data into Glean search for faster resolution, trend insights, and reliable tracking – all from within one interface.

## Pre-installation considerations[​](#pre-installation-considerations "Direct link to Pre-installation considerations")

-   You must have administrator access to Rootly and Glean.
-   In Glean, you must configure an [Indexing API Authentication](https://developers.glean.com/api-info/indexing/authentication/overview). The Indexing API only supports Glean-issued tokens.
-   Python 3.13+

## Installation instructions[​](#installation-instructions "Direct link to Installation instructions")

Visit the [Rootly integrations documentation](https://docs.rootly.com/integrations/glean) for instructions on setting up Glean for Rootly.
