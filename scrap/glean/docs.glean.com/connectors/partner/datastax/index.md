On this page

Glean is proud to partner with [Datastax](https://www.datastax.com/) to provide a seamless experience for your team. Refer the [Datastax documentation](https://docs.datastax.com/en/astra-db-serverless/integrations/glean.html) or contact their support team with any questions.

The Datastax connector enables developers to easily transfer and use data between platforms, leveraging Glean's powerful retrieval to enrich GenAI applications. By combining [Datastax's Astra DB](https://www.datastax.com/products/datastax-astra) with Glean's multi-source aggregated search, you unlock new agentic app workflows and efficiently create context-aware GenAI solutions.

## Features[​](#features "Direct link to Features")

-   **DataStax Langflow component:** Integrates Glean's Search API within Langflow implementations, enhancing context for agents and driving informed decision-making.
-   **Unified query:** Enables Glean to provide a natural language interface for querying data stored in Astra DB.

## Benefits[​](#benefits "Direct link to Benefits")

Securely integrate Astra DB data into Glean, empowering developers to build efficient, context-aware GenAI applications. The combined solution streamlines knowledge discovery and allows structured database information to ground AI answers reliably.

For more information, read [Glean integration](https://www.datastax.com/integrations/glean) and [Glean and DataStax join forces to help developers harness powerful enterprise search](https://www.glean.com/blog/glean-datastax-integration) blog.

## Pre-installation considerations[​](#pre-installation-considerations "Direct link to Pre-installation considerations")

-   You must have administrator access to Glean.
-   In Glean, you must configure an [Indexing API Authentication](https://developers.glean.com/api-info/indexing/authentication/overview). The Indexing API only supports Glean-issued tokens.

## Installation instructions[​](#installation-instructions "Direct link to Installation instructions")

Visit the [Datastax integrations documentation](https://docs.datastax.com/en/astra-db-serverless/integrations/glean.html) for instructions on setting up Glean for Datastax.
