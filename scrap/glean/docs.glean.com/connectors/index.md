On this page

Glean connectors bring content from your company's apps into Glean, so it's searchable and available to Glean Assistant with each source's access permissions enforced. Browse the connectors below for setup guides and supported content.

If there's no native connector for your source, build a [custom connector](/connectors/custom/about), use a [partner connector](/connectors/partner/), or start with [About connectors](/connectors/about).
