On this page

Use the following pages to set up Tableau in Glean:

## Set up Tableau indexing[​](#set-up-tableau-indexing "Direct link to Set up Tableau indexing")

The [Indexing](/connectors/native/tableau/connector) page explains the shared requirements and supported content. Use one of the method-specific setup pages for the complete Tableau and Glean procedure:

-   [Set up using Connected App](/connectors/native/tableau/setup-connected-app): configure indexing and Tableau in Assistant with Connected App credentials.
-   [Set up using Personal Access Token](/connectors/native/tableau/setup-personal-access-token): configure PAT-based indexing and per-user Tableau access.

## Enable Tableau in Assistant[​](#enable-tableau-in-assistant "Direct link to Enable Tableau in Assistant")

If you use Connected App setup, follow [Tableau in Assistant](/connectors/native/tableau/assistant) to complete the connector's **Connect** step and configure access to Tableau tools.

note

The **Connect** step appears in the Tableau connector wizard after you complete **Set up indexing** and select **Continue**. You do not start Tableau tool setup from the generic **Tools** page.
