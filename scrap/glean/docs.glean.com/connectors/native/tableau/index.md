# Find Tableau dashboards and ask natural-language questions about Tableau data in Glean

Search for Tableau workbooks and data sources through the indexed connector, then complete the connector's Connect step to let users ask natural-language questions and retrieve live data from Tableau. View metadata may appear within the parent workbook. Always scoped to each user's Tableau permissions.

Indexed by defaultNatural-language queriesPer-user authPermission-aware

[Set up indexing](/connectors/native/tableau/connector)[See how it works](/connectors/native/tableau/overview)

Beta availability

The Tableau Connected App setup and Tableau in Assistant are currently beta features and aren't enabled by default. Contact your Glean representative or [Glean Support](https://support.glean.com) to confirm whether your deployment has access.
