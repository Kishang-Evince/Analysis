On this page

Ask clear questions and give Glean enough context to find and produce the best results.

## End questions with a question mark[​](#end-questions-with-a-question-mark "Direct link to End questions with a question mark")

End questions with a question mark (?). That helps Glean treat your input as a question rather than a keyword search.

## Name the connector[​](#name-the-connector "Direct link to Name the connector")

Include the connector name when you want results from a specific app.

Instead of:

`Provide me some sample support tickets`

Ask:

`Can you provide some sample support tickets from Zendesk?`

## Filter by application[​](#filter-by-application "Direct link to Filter by application")

Use application filters to narrow results to the apps that matter for your question.

## Use connector parameters in search[​](#use-connector-parameters-in-search "Direct link to Use connector parameters in search")

For global searches, add a connector as a search parameter with `app:connectorname`. For example, `app:zendesk` or `app:gdrive`.

## Tag a specific document[​](#tag-a-specific-document "Direct link to Tag a specific document")

To ask about a specific document, paste its link or type `@` followed by the document name.

## Search the web[​](#search-the-web "Direct link to Search the web")

Toggle **Search the web** to include public web results alongside your company knowledge.

## Use clear language[​](#use-clear-language "Direct link to Use clear language")

Write questions in clear, simple language. Avoid slang and abbreviations.

**Instead of:**

`What's the ROI on implementing AI-driven CRM?`

**Better:**

`Could you explain the expected benefits of using AI in customer relationship management systems?`

## Break down complex questions[​](#break-down-complex-questions "Direct link to Break down complex questions")

If a question has multiple parts, split it into smaller, focused questions.

## Provide context[​](#provide-context "Direct link to Provide context")

Include relevant background so Glean can interpret the question and return a more useful answer.

## Put keywords in quotation marks[​](#put-keywords-in-quotation-marks "Direct link to Put keywords in quotation marks")

Place important keywords in double quotes to emphasize them. For example:

`Please provide recent customer tickets for the "XYZ" customer from the ticketing tool or connector "ABC".`

## Prefer Thinking mode for company topics[​](#prefer-thinking-mode-for-company-topics "Direct link to Prefer Thinking mode for company topics")

For company-specific topics, use **Thinking mode** to get more thorough answers with citations from your company knowledge. **Fast mode** prioritizes speed and may not search company knowledge for every query.

## Add company context for better citations[​](#add-company-context-for-better-citations "Direct link to Add company context for better citations")

If you're not seeing citations, rephrase the question to include company-specific context, such as a team name, project, or internal term.
