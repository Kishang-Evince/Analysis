On this page

As you work in Glean, you can rename conversations and queue follow-up messages to keep your chats organized and moving. To find, filter, or delete earlier conversations, see [Search chat history](/user-guide/assistant/glean-chat/search-past-chats).

## Rename a chat[​](#rename-a-chat "Direct link to Rename a chat")

Glean automatically generates a title for each new chat. You can rename any chat you own to give it a more meaningful title, making past conversations easier to find and organize.

1.  In the left navigation, find the chat you want to rename and open its options menu.
2.  Select **Rename**.
3.  In the **Rename chat** dialog, enter a new title (up to 80 characters) and select **Save**.

Custom titles persist across sessions. Chats you don't rename keep their automatically generated titles, so no action is required.

## Queue messages[​](#queue-messages "Direct link to Queue messages")

While Glean generates a response, you can send another message to add it to a queue instead of interrupting the response in progress. Queued messages appear as a list above the composer and run in order automatically, as each response completes.

-   **Queue multiple messages.** You can stack several follow-ups while a response runs.
-   **Runs in order.** Glean processes queued messages one at a time, in the order you sent them. Each queued message starts after the previous response finishes.
-   **Persists across sessions.** Queued messages persist across chat sessions, so they remain if you refresh the page or reconnect.

Before a queued message runs, you can act on it from its row in the queue:

-   **Edit** the message text.
-   **Delete** the message to remove it from the queue.
-   **Send now** to run the message immediately instead of waiting for its turn.
