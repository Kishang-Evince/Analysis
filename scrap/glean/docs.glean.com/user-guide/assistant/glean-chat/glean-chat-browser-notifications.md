On this page

Glean supports *browser notifications* for chat responses, ensuring employees are alerted when a reply is available and the Glean browser tab is not active. Notifications allows you to return directly to the relevant chat thread with a single click and the content is limited to chat context awareness. This feature works within existing OS and browser security models.

Notifications are available across all chat modes like Fast, Thinking, Deep Research, and Agents. Notifications are enabled at the individual level and you can disable it at any time.

## Prerequisites[​](#prerequisites "Direct link to Prerequisites")

You need access to Glean in a supported browser and permission to change notification settings for your account.

## Key benefits[​](#key-benefits "Direct link to Key benefits")

-   Increased productivity: You can continue working in other applications while awaiting responses.
-   Timely updates: Notifications appear as soon as replies are ready, even for long-running queries.
-   Seamless navigation: Each notification links directly back to the relevant chat.

## Setup steps[​](#setup-steps "Direct link to Setup steps")

### Enabling browser notifications[​](#enabling-browser-notifications "Direct link to Enabling browser notifications")

To receive notifications, perform the following steps:

1.  In Glean, open **Home page settings** on the top right corner.
2.  Click **Manage more settings**.
3.  Click **Preferences** → **Notifications** and enable notifications.
    
    -   Each user must enable notifications when they receive the alert in Glean.
4.  When prompted by your browser to allow notifications, select **Allow** to grant permission.
    
5.  Verify that notifications for the chosen browser are enabled at the operating system (OS) level.
    

If you have enabled the notifications in Glean setting, browser and on the OS level, you will see the notification after Glean is ready with the answer for your query.

note

*Do not disturb* mode must be turned off.

### Disabling browser notifications[​](#disabling-browser-notifications "Direct link to Disabling browser notifications")

To disable notification, perform the following step:

1.  In Glean, open **Home page settings** on the top right corner.
2.  Click **Manage more settings**.
3.  Click **Preferences** → **Notifications** and disable notifications.

## Troubleshooting steps[​](#troubleshooting-steps "Direct link to Troubleshooting steps")

If notifications are not appearing:

-   Revisit **Preferences** in Glean settings to confirm **Notification** setting is still enabled.
-   Confirm that notifications are enabled in the browser.
-   Verify that OS-level settings permit notifications for the browser.
-   Ensure the Glean tab is not in focus, notifications only appear when it is inactive.
