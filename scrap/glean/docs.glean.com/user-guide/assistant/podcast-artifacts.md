On this page

Create a podcast in Glean Assistant to turn information from across your organization into a playable audio artifact. Glean researches your request, writes a script optimized for listening, and returns the audio with a paired transcript.

note

Podcast artifacts are available only for organizations using Glean Key. Customer Key support isn't available. The feature is off by default while it's under managed rollout, so ask your admin if you don't see it.

## Create a podcast[​](#create-a-podcast "Direct link to Create a podcast")

In Glean, ask for a podcast and describe what you want to learn. Include the topic, audience, and approximate length to guide the result.

For example:

> Create a 5-minute podcast for a new team member explaining your organization's product priorities. Use the latest project updates and cover the main decisions and open questions.

Glean researches the relevant information it can access, creates a script designed for listening, and generates the audio artifact in the conversation.

## Listen to and review the artifact[​](#listen-to-and-review-the-artifact "Direct link to Listen to and review the artifact")

The audio artifact includes a player and a transcript. You can:

-   Play or pause the audio.
-   Seek to a different point in the recording.
-   Change the playback speed.
-   Read the transcript while you listen.

If audio generation fails, click **Retry audio**.

## Refine and share a podcast[​](#refine-and-share-a-podcast "Direct link to Refine and share a podcast")

Continue the conversation to refine the podcast. You can ask Glean to:

-   Focus on a different aspect of the topic.
-   Refresh the sources behind the script.
-   Change the length or level of detail.

Glean saves each round of changes as a new version of the artifact. From the three-dot menu on the player, click **Share** to give teammates access or **Download** to save as an MP3. Podcasts you create stay in the **Audio** section of your [Library](/user-guide/assistant/assistant-library).

## Get better results[​](#get-better-results "Direct link to Get better results")

-   **Name the audience.** Tell Glean whether the podcast is for an executive, a new employee, a customer meeting, or someone else.
-   **Set the scope.** Point Glean at the documents, projects, teams, or date range it should draw on.
-   **Describe the format.** A briefing, an onboarding walkthrough, and a project update each produce a different script.
-   **Set a length.** A target duration tells Glean how much detail to include.

## Limitations[​](#limitations "Direct link to Limitations")

-   [Real-time voice](/user-guide/assistant/real-time-voice) is a separate feature and doesn't produce audio artifacts.
-   Generating podcasts count toward [usage limits](/administration/management/usage/set-usage-limits-and-alerts). Both script and audio synthesis work are billable. When the usage limit is reached, you can't generate new podcasts until the limit resets at the start of the next calendar month.
