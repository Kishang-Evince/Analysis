On this page

Chat sharing lets you share entire conversation threads with specific users, departments, or everyone in your workspace.

### Easy to use

No more clunky exports or partial screenshots! Get the whole conversation as you see it.

### Upholds doc permissions

Recipients will only see documents and citations that they can access.

## How to share a chat[​](#how-to-share-a-chat "Direct link to How to share a chat")

You can control sharing options in the top right corner of the chat window.

Click on the **Share** button, choose which users and departments to share this chat with, and select **Save**. You can also grant access to your whole organization under **General access**.

You can copy the URL using the copy button, or directly from the URL bar in your browser. Sharing does not send notifications at this time, so you will still need to share the link via message or email.

## Share a prefilled message link[​](#share-a-prefilled-message-link "Direct link to Share a prefilled message link")

You can share a link that opens Glean with a message already entered in the composer. Add the `message` parameter to a Glean chat URL and set its value to a URL-encoded prompt, for example [https://app.glean.com/chat?message=Summarize%20the%20latest%20product%20launch](https://app.glean.com/chat?message=Summarize%20the%20latest%20product%20launch).

The link only prefills the message. Whoever opens it reviews the text and clicks **Send** (or **Run** for an agent) to run it. Glean never submits a prefilled message automatically, so each person can edit it before running and every response stays personalized to their permissions.

## Privacy and security controls[​](#privacy-and-security-controls "Direct link to Privacy and security controls")

Chat sharing includes comprehensive privacy controls to protect sensitive information:

### Document-level controls

**Automatic permission checking**: The system automatically checks if recipients have access to cited documents. Users without permissions see redacted placeholders instead of sensitive content.

### Uploaded file access

**File downloads**: If a shared chat contains uploaded files, only the original uploader and users with access to the shared chat session can download those files.

### User controls

**Individual management**: You can:

-   Rescind shared links at any time
-   Review who has access to your shared chats

warning

Always review your chat content before sharing to ensure no sensitive information is inadvertently included.

note

Glean conversations are retained for 30 days. As a result, a shared chat is only available for 30 days after it was first created, after which the link will no longer work.

## Use cases[​](#use-cases "Direct link to Use cases")

Chat sharing supports various collaboration scenarios:

### Knowledge transfer

Solved something in Glean? Send the full analysis/investigation so others can follow up at their own pace.

### Workflow demonstration

Share effective prompts, techniques and followups with full context.

### Analysis review

Share research conversations for easy review, so others can independently check your methodology and validate your findings.

### Agents showcase

Built an awesome agent? Show your users exactly what the output looks like without them needing to run the agent themselves!

## Best practices[​](#best-practices "Direct link to Best practices")

Follow these guidelines to make the most of chat sharing:

### Review before sharing

Always review your conversation content before sharing to ensure it's appropriate for your intended audience and doesn't contain sensitive information.

### Use descriptive titles

Give your shared chats meaningful titles that help recipients understand the content and purpose.

### Consider your audience

Choose appropriate sharing permissions based on your audience's access levels and the sensitivity of the content.
