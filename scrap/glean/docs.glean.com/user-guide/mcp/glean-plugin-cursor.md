On this page

Install the Glean plug-in directly from the Cursor Marketplace.

## Prerequisites[​](#prerequisites "Direct link to Prerequisites")

Before you begin:

-   Ensure that you have Cursor version 3.8.11 or later
-   Ask your Glean administrator to complete the [Glean plug-in prerequisites](/administration/platform/mcp/glean-plugin#prerequisites)

note

Earlier Cursor versions prevent human-in-the-loop approval for write tools from functioning properly. Upgrade to make sure tool approvals and file edits work securely.

## Install the plug-in[​](#install-the-plug-in "Direct link to Install the plug-in")

1.  Open **Cursor Settings**.
2.  Go to **Marketplace**.
3.  Search for **Glean**.
4.  Click **Add to Cursor**.
5.  Reload Cursor if prompted.
6.  Confirm that `/glean_run` is available.

For current Cursor requirements and installation steps, see [Glean Plugin for Cursor](https://developers.glean.com/guides/mcp/cursor) on the Developer Portal.
