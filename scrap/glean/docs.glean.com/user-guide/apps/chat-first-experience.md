On this page

Use Glean for Desktop to search or chat without leaving the app you're working in.

-   **Quick Entry** opens a compact search or chat bar. The default shortcut is `⌘+⇧+J` on macOS and `Ctrl+Shift+J` on Windows
-   **Quick Chat** opens a floating chat window that stays on top of other apps
-   **Take screenshot** attaches a screenshot to your message so Glean can use it as context

## Prerequisites[​](#prerequisites "Direct link to Prerequisites")

Install [Glean for Desktop](/user-guide/apps/glean-for-desktop) before configuring shortcuts or using Quick Chat.

## Configure desktop shortcuts[​](#configure-desktop-shortcuts "Direct link to Configure desktop shortcuts")

In the Glean desktop app, open your profile menu and go to **Settings → Desktop app**.

### Set quick entry behavior[​](#set-quick-entry-behavior "Direct link to Set quick entry behavior")

In the **Quick Entry** section:

1.  Enter a key combination in **Quick entry shortcut**. Clear the field to remove the shortcut.
2.  Set **Default quick entry mode** to **Chat** or **Search**. **Chat** is the default.
3.  Set **Open new chats** to **In Quick Chat** or **In Main Window**. **In Quick Chat** is the default.
4.  Turn on **Open quick entry results in browser** if you want chat and search results to open in your default browser.

### Set floating chat options[​](#set-floating-chat-options "Direct link to Set floating chat options")

In the **Quick Chat** section:

1.  Enter a key combination in **Quick chat shortcut**. Quick Chat doesn't have a default shortcut.
2.  Set **Quick chat behavior** to **Toggle window** or **Open new window**:
    -   **Toggle window** shows or hides the same Quick Chat window
    -   **Open new window** opens another Quick Chat window each time you use the shortcut

### Allow screenshots on macOS[​](#allow-screenshots-on-macos "Direct link to Allow screenshots on macOS")

Before you take screenshots in Quick Chat, allow Glean to record your screen:

1.  Under **Permissions**, click **Enable** next to **Screen Recording**.
2.  Turn on access in **System Settings → Privacy & Security → Screen Recording**.
3.  Restart the Glean desktop app.

note

Windows doesn't require an equivalent Screen Recording setting.

## Search or chat from any app[​](#search-or-chat-from-any-app "Direct link to Search or chat from any app")

-   Press your **Quick entry shortcut** to open the search or chat bar
-   Press your **Quick chat shortcut** to open the floating Quick Chat window

### Attach a screenshot[​](#attach-a-screenshot "Direct link to Attach a screenshot")

1.  Open Quick Chat.
2.  In the chat composer, click **Take screenshot**.
3.  Enter a question about the screenshot and send your message.
