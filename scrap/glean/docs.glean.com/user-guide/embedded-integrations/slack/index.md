On this page

Glean in Slack brings enterprise search and AI-powered answers directly into your Slack workspace. Find documents, get instant answers in channels, chat with Assistant in the sidebar, and stay on top of what matters with a personalized daily digest.

## What you can do[​](#what-you-can-do "Direct link to What you can do")

| Feature | What it does |
| --- | --- |
| [**/glean search**](/user-guide/embedded-integrations/slack/search-with-glean) | Search all connectors from Slack |
| [**Ask questions in channels**](/user-guide/embedded-integrations/slack/ask-questions-channels) | Get AI-powered answers directly where conversations happen |
| [**Slack sidebar**](/user-guide/embedded-integrations/slack/use-slack-sidebar) | Access the full Glean Assistant interface in Slack |
| [**Daily Digest**](/user-guide/embedded-integrations/slack/subscribe-daily-digest) | Subscribe to morning summaries of channels and topics |
| [**Code Writer**](/user-guide/embedded-integrations/slack/use-code-writer) | Turn Slack conversations into draft pull requests |
| [**Public Mode**](/user-guide/embedded-integrations/slack/understand-public-mode) | View answers shared with the entire channel |

Need a feature enabled?

Glean in Slack is set up and configured by your Glean admin. If a feature isn't available in your workspace, see [Admin Guide](/administration/platform/embedded-integrations/slackbot/).

## Requirements[​](#requirements "Direct link to Requirements")

-   Your organization has Glean enabled and connected to Slack
-   You're signed in to Slack with an account known to Glean
-   The features you want to use are turned on by your admin
