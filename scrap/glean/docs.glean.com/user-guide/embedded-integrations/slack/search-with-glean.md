On this page

The `/glean` command lets you search across all your company's connectors directly from any Slack channel. You can find documents, tickets, wiki pages, and more without leaving Slack.

## How to use the /glean command[​](#how-to-use-the-glean-command "Direct link to How to use the /glean command")

Type `/glean` followed by your search query in any Slack channel. Glean returns relevant results from across your connectors.

For example:

-   `/glean onboarding checklist`
-   `/glean PTO policy`
-   `/glean deploy process for payments-service`

Search results are visible only to you, with an option to share them back to the channel.

note

This feature is enabled by default and cannot be modified. It is available to all Glean customers who have installed the Glean Slack app, and it does not require Glean Assistant access.
