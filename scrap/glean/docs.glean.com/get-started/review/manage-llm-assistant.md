On this page

Glean Assistant uses both company and public knowledge to help users create, summarize, analyze, and execute work. Use this task to choose your LLM provider and define how Assistant responds before launching to end users.

tip

This task is optional and you can complete it at any time.

## Open the Assistant setup[​](#open-the-assistant-setup "Direct link to Open the Assistant setup")

In the **Prepare your workspace for better results** section, select **Manage LLM and Assistant settings** to choose your LLM provider and configure how Assistant responds.

![Manage LLM and Assistant settings](/img/get-started/manage-llm-assistant-task.webp)

Manage LLM and Assistant settings

To open this task directly, go to **Platform → Assistant** in the **Admin console**. To skip and configure later, select the **Skip** option.

## What you can configure[​](#what-you-can-configure "Direct link to What you can configure")

From the Assistant setup page, you can:

-   Select your preferred LLM provider. Glean supports OpenAI, Anthropic, Google, and Amazon models via the [Model Hub](/administration/llms).
-   Define [custom instructions](/administration/assistant/configuration/custom-instructions) that shape how Assistant responds.
-   Apply [content restrictions](/administration/assistant/configuration/content-restrictions) to control which content Assistant can use.
-   Configure [chat history retention](/administration/assistant/configuration/chat-history).
