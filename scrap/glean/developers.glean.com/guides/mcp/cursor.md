# Glean plugin for Cursor

You use Cursor. Glean brings the enterprise context.

Installation

1

Set up the Glean MCP Server

The plugin requires a Glean MCP connection. Use the Glean configurator to connect Cursor to your organization's Glean instance. Authentication uses Glean's OAuth server where enabled, or a Glean API token as a fallback.

[Open MCP Configurator](https://app.glean.com/settings/install?mcpConfigure=true&mcpHost=cursor)

2

Install the Glean Plugin

Find and install the Glean plugin directly from Cursor Settings.

1.  Open Cursor Settings → Marketplace
2.  Search for "Glean"
3.  Click Add to Cursor
