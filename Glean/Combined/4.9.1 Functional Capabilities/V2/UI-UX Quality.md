## Claims

| Sr No | Claim | Source | Detail |
|---|---|---|---|
| 1 | A first-party, formal Accessibility Conformance Report exists | [docs.glean.com/user-guide/about/accessibility](https://docs.glean.com/user-guide/about/accessibility) | Verbatim: *"Glean maintains an up-to-date Accessibility Conformance Report (ACR), based on the Voluntary Product Accessibility Template (VPAT) 2.5 format, covering WCAG 2.0, 2.1, and 2.2 at Levels A and AA."* |
| 2 | The ACR is gated behind a procurement request, not openly published | [docs.glean.com/user-guide/about/accessibility](https://docs.glean.com/user-guide/about/accessibility) | *"To review the ACR as part of an evaluation or procurement, request a copy from our Trust Center Resources Page"* - not a public download. |
| 3 | The design system was rebuilt on a foundation specifically chosen for accessibility | Third-party corroborated, [glean.com/blog/designing-glean-for-accessibility-design-compliance](https://www.glean.com/blog/designing-glean-for-accessibility-design-compliance) | Design system rebuilt on *"Base UI"*, described as bringing *"better screen reader and keyboard accessibility out of the box."* |
| 4 | No independent usability score (SUS, task-completion benchmark, etc.) was found | Absence checked via targeted search | No first-party or independently-audited usability metric found - accessibility conformance (claims 1-3) is a real signal, but is a different measure from subjective ease-of-use. |
| 5 | The SOW's own cognitive-walkthrough methodology cannot be satisfied by documentation alone | Inherent to the claim type | This field's evaluation methodology explicitly calls for a live cognitive walkthrough with a business user, rated 1-5 - that rating genuinely cannot be produced from docs research and must come from the companion test guide's hands-on session. |
| 6 | Browser notifications alert users when a chat reply is ready, but only while the Glean tab is inactive | [docs.glean.com/user-guide/assistant/glean-chat/glean-chat-browser-notifications](https://docs.glean.com/user-guide/assistant/glean-chat/glean-chat-browser-notifications) | Verbatim: *"Notifications allows you to return directly to the relevant chat thread with a single click... Notifications are available across all chat modes like Fast, Thinking, Deep Research, and Agents."* Requires a three-level opt-in: Glean **Preferences → Notifications**, the browser's own permission prompt, and OS-level notification settings for that browser - all three must be on, and *"Do not disturb mode must be turned off."* Per-user, not org-wide. |
| 7 | Chats can be renamed, and follow-up messages can be queued while a response is still generating | [docs.glean.com/user-guide/assistant/glean-chat/manage-chats](https://docs.glean.com/user-guide/assistant/glean-chat/manage-chats), re-fetched live 2026-09-14 | Verbatim: rename supports *"a new title (up to 80 characters)"* that *"persist\[s\] across sessions."* Queueing: *"send another message to add it to a queue instead of interrupting the response in progress"* - *"Queued messages persist across chat sessions,"* run *"one at a time, in the order you sent them,"* and each can be **Edit**ed, **Delete**d, or **Send now**'d before its turn. |
| 8 | Past chats and agent runs are searchable from the sidebar, admin-gated, with a per-user opt-out independent of the org setting | [docs.glean.com/user-guide/assistant/glean-chat/search-past-chats](https://docs.glean.com/user-guide/assistant/glean-chat/search-past-chats) | Verbatim: search via *"Cmd+K (Mac) or Ctrl+K (Windows/Linux)"*, filterable by *"Documents, Emails, Messages, Images, Slides, or All chats."* Gated: *"Your admin must enable Chat history before you can search past chats."* Even when on org-wide, *"you can opt out for your own account"* under **Settings → Preferences → Privacy**, and can *"delete your history at any time."* No custom retention-day count - only on/off per user, following the org's configured retention period. |
