## Headline

Moderate - core setup (workspace, first connectors, basic search) is a genuinely guided, wizard-driven process that Glean's own docs and marketing claim can happen in as little as "less than 2 hours," but a *real* org-wide rollout is a multi-week, multi-team effort once SSO/identity readiness, permissions modeling, and connector-by-connector admin access are factored in - Glean's own community guidance puts a realistic mid-sized enterprise implementation at 4-5 weeks, and this project's own prior research already documents specific friction points (Teams multi-portal Azure Bot Service registration, OIDC-vs-SAML directory-sync tradeoffs, a permanent AWS region decision). A definitive "engineering experience" rating requires this project's own hands-on pilot, tracked in the companion test guide - what follows is a preliminary, honestly-caveated rating built from documented setup steps and third-party review signals, not first-hand deployment experience.

## Independent read

- The single biggest gap in "rating" this field from desk research alone is that every complexity signal found is either a vendor-marketing figure (optimistic, unverified against a real multi-connector, multi-team healthcare rollout), a search-engine-summarized third-party review (not independently, individually verified this pass), or this project's own prior findings about specific integration friction points (real, but not yet assembled into a single end-to-end timed rollout). None of these substitutes for an actual tracked pilot.
- Claims 2-4 show three different numbers for essentially the same question ("how long does deployment take") depending on scope: 1-3 weeks (vendor, narrow/first-value framing), 4-5 weeks (community resource, mid-sized enterprise, phase-aware), and 3-6 months (reported full org-wide scaling). All three can be simultaneously true depending on what "deployed" means - this ambiguity itself is a finding worth surfacing to the client rather than picking one number.
- Claims 6-8 are the most concrete, doc-verified complexity drivers available and should carry more weight in a preliminary rating than the vendor's "under 2 hours" framing, which describes only the initial workspace/first-connector step, not a healthcare-scale, multi-connector, SSO-integrated, permissions-modeled rollout.
