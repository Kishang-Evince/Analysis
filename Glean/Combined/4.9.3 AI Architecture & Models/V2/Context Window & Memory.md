## Headline

Memory is a well-documented, deliberately-scoped, configurable system with a hard **2-hour ceiling** regardless of settings. Context window size, by contrast, is **not one number** - it varies by model, changes automatically for some models, and the exact chat-turn token cap is never publicly disclosed. Truncation happens silently in at least one documented case, with no stated end-user warning mechanism.

## Independent read

- Claims 1-4 show a genuinely thoughtful, documented memory architecture - the 2-hour cap and sub-agent isolation are both sensible, deliberate design choices, not accidental gaps.
- Claims 5-6 are the field's real weak spot for a buyer: "what happens when I hit the limit" has a partially-answered story (silent partial document read) and a fully-undisclosed number (chat-turn token cap). Neither is a defect exactly, but both should be flagged as things a buyer should ask Glean directly to quantify for their specific tenant/model mix.
- Claims 7-8 together mean "context window" cannot be answered with one number for this vendor - it must be answered per-model, and the evaluation should note it as a moving target (already demonstrated moving twice: up for GPT-4.1, down for Claude Sonnet).
