On this page

Choose which nav items appear in Glean's left navigation for people who haven't customized it themselves.

note

You must have the **Admin** or **Super Admin** role to set left navigation defaults, or change workspace appearance settings in general.

## Set the default nav items[​](#set-the-default-nav-items "Direct link to Set the default nav items")

1.  In the **Admin console**, go to **Appearance**.
2.  Under **Sidebar navigation defaults**, turn nav items on or off.
3.  Wait a few minutes for the changes to apply.

Nav items you turn on appear directly in the left navigation. Items you turn off move into the **More** dropdown at the end of the navigation. Glean keeps some items, such as **New chat**, fixed in the navigation, so you cannot turn them off.

The nav items you can set depend on the features enabled for your organization. They may include **Search**, **Library**, **Agents**, **People**, **Projects**, and **Meeting notes**.

These defaults apply only to people who haven't customized their left navigation. Individual choices take precedence over the workspace defaults.
