This catalog lists 881 remote mcp server templates across 880 unique server names.

A server name can appear in multiple sections when Glean offers templates with different verification statuses for that server. Always check the verification status of the specific template you select.

## Search the catalog[​](#search-the-catalog "Direct link to Search the catalog")

To check whether a specific vendor or server appears in the catalog, use the browser search feature:

-   **macOS:** Press ⌘ + F
-   **Windows / Linux:** Press Ctrl + F

## Verification statuses[​](#verification-statuses "Direct link to Verification statuses")

Glean manages template availability and verification status separately. Glean can mark a generally available server template as **Preview** if Glean has not yet vetted the connection.

| Status | Definition |
| --- | --- |
| **Glean-certified** | Glean tested connectivity, authentication, and key workflows. |
| **Provider-managed** | Glean verified the connection. The third-party provider manages tool quality and maintenance. |
| **Preview** | Glean did not vet connectivity, authentication, or tool quality. Setup and behavior can vary. Contact Glean Support if you encounter setup issues. |

## Setup instructions by deployment date[​](#setup-instructions-by-deployment-date "Direct link to Setup instructions by deployment date")

The creation date of your Glean deployment determines how you configure an mcp integration. Glean does not automatically move existing configurations out of their current setup flow.

### Deployments created on or after September 22, 2026[​](#deployments-created-on-or-after-september-22-2026 "Direct link to Deployments created on or after September 22, 2026")

1.  Navigate to **Connectors** to set up catalog-backed mcp integrations.

### Deployments created before September 22, 2026[​](#deployments-created-before-september-22-2026 "Direct link to Deployments created before September 22, 2026")

1.  Check **Connectors** first to locate your integration.
2.  If **Connectors** does not list the integration, navigate to **Platform → Tools** to complete setup.
