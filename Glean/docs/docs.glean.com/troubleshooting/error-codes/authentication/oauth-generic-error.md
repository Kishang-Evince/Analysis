## Issue[​](#issue "Direct link to Issue")

An OAuth error occurred that does not match a specific error category. This is a catch-all for unclassified OAuth failures.

## Resolution[​](#resolution "Direct link to Resolution")

1.  Retry the OAuth flow from the Glean **Admin console**.
2.  If the error persists, note the full error message and any details shown on the error page.
3.  Contact [Glean Support](https://support.glean.com) with the error details and timestamps for further investigation.

For additional assistance, contact [Glean Support](https://support.glean.com).
