## Issue[​](#issue "Direct link to Issue")

The PubSub topic or subscription for Gmail activity could not be validated.

## Resolution[​](#resolution "Direct link to Resolution")

A PubSub setup step must be performed by Glean Admins. Please contact Glean Support for assistance: [https://support.glean.com](https://support.glean.com)
