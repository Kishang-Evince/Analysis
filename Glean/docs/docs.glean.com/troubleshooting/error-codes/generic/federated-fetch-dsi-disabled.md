## Issue[​](#issue "Direct link to Issue")

Search results for the connector corresponding to the queried URL is disabled in your Glean instance.

## Resolution[​](#resolution "Direct link to Resolution")

A Glean Administrator with Setup Admin role can re-enable the connector in the **Admin console**.

Please contact Glean Support for additional help.
