## Issue:[​](#issue "Direct link to Issue:")

The user does not have the necessary permissions to initiate a chat with Gemini.

## Resolution:[​](#resolution "Direct link to Resolution:")

Ensure that the required APIs are enabled and the user has the necessary roles per the [prerequisites](/tools/connector/googlecloud#prerequisites).

If you are still having difficulty please reach out to us: [https://support.glean.com](https://support.glean.com)
