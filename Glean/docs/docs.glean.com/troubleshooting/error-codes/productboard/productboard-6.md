## Issue[​](#issue "Direct link to Issue")

Setup validation found no notes in the Productboard workspace on the first page of results. This is a warning, not a failure: the connector can finish setup, but it has no notes to index.

## Resolution[​](#resolution "Direct link to Resolution")

-   Add notes in Productboard, then re-run the connector so Glean can index them.
-   Continue without notes if the workspace is intentionally empty.

For additional assistance, contact [Glean Support](https://support.glean.com).
