## Issue[​](#issue "Direct link to Issue")

Setup validation found no roadmap features in the Productboard workspace on the first page of results. This is a warning, not a failure: the connector can finish setup, but it has no roadmap entities to index.

## Resolution[​](#resolution "Direct link to Resolution")

-   Add roadmap content (products, components, features, or subfeatures) in Productboard, then re-run the connector so Glean can index it.
-   Continue without roadmap content if the workspace is intentionally empty.

For additional assistance, contact [Glean Support](https://support.glean.com).
