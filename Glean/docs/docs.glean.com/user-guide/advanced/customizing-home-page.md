On this page

Your Glean home page is customizable to match your workflow and preferences. Some options are available directly from the home page, and others are available in the Preferences menu. To customize the destinations in the left navigation, see [Customize the left navigation](/user-guide/advanced/customizing-left-navigation).

## Prerequisites[​](#prerequisites "Direct link to Prerequisites")

You need access to the Glean homepage and permission to change your profile preferences.

## How to customize your homepage[​](#how-to-customize-your-homepage "Direct link to How to customize your homepage")

### Open home page settings[​](#open-home-page-settings "Direct link to Open home page settings")

The way you open home page settings depends on which homepage experience your organization uses:

-   **New homepage**: Select your profile picture in the bottom-left corner, then select **Settings**.
-   **Older homepage**: Select the home page settings icon in the upper-right corner.

Either option opens the home page settings panel with the following settings:

-   **General**: Control basic behavior of the Glean home page. This section only appears if you have the [Glean browser extension](https://chrome.google.com/webstore/detail/glean/cfpdompphcacgpjfbonkdokgjhgabpij) installed.
-   **Theme**: Choose your preferred theme for the Glean home page.
-   **Background**: Choose from static and scenic wallpapers to personalize your background. Your admin can turn this off, in which case the section doesn't appear.
-   **Layout**: Customize how content is displayed on your home page.
-   **Composer behavior**: Choose how the Enter key behaves in the composer, if your organization's composer supports this setting.

## Customize the home page using the Preferences menu[​](#customize-the-home-page-using-the-preferences-menu "Direct link to Customize the home page using the Preferences menu")

The Preferences menu contains more advanced settings for customizing your home page. To access the **Preferences** menu:

1.  Select your profile picture.
2.  Select **Settings** (or **Your settings**, depending on your homepage experience).
3.  Make sure you're on the **Preferences** tab.

## Home page settings customization options[​](#home-page-settings-customization-options "Direct link to Home page settings customization options")

You can customize most of the following home page settings using either the home page settings panel or the Preferences menu. Preferred language is available only in the Preferences menu.

### General[​](#general "Direct link to General")

Control basic behavior of the Glean home page.

-   **Open Glean when you create a new browser tab**: When this preference is on, Glean appears for every new browser tab.
-   **Show bookmarks bar**: Toggle this to show or hide the bookmarks bar for quick access to saved links.
-   **Show shortcuts**: Toggle this to show or hide shortcuts to commonly visited pages or apps.

### Theme[​](#theme "Direct link to Theme")

-   **Light**: A bright, classic look.
-   **Dark**: A sleek, low-light theme that's easy on the eyes.
-   **System**: Automatically matches your operating system's light or dark mode setting.

### Background[​](#background "Direct link to Background")

Choose from static and scenic wallpapers to personalize your background.

-   Tap any image to apply it.
-   To remove wallpaper, select the blank option in the top-left.

If you don't see a **Background** section, your admin has turned off background changes for your organization. Everyone then sees the wallpaper your admin set, and any background you picked earlier no longer displays.

### Layout[​](#layout "Direct link to Layout")

Customize how content is displayed on your home page.

-   **Simple**: A minimal and focused layout, useful if you prefer a clean workspace.
-   **Informational** (default): Displays personalized activity cards, your calendar, mentions, and other helpful content.

### Preferred language[​](#preferred-language "Direct link to Preferred language")

Choose your preferred language for the Glean home page. This setting is available in the Preferences menu only.

### Composer behavior[​](#composer-behavior "Direct link to Composer behavior")

Choose how the composer (the box where you type search queries or chat prompts) responds to keyboard shortcuts on the home page. Depending on your organization's rollout, you may see one or more of these options:

-   **Default**: Enter starts a chat (including search results when relevant). Option/Alt+Enter starts a search.
-   **Multi-line**: Enter inserts a new line. Command+Enter on macOS or Ctrl+Enter on Windows submits the message to chat.
-   **Search priority**: Enter starts a search. Option/Alt+Enter starts a chat.

**Multi-line** and **Search priority** are rolled out independently, so your organization may have one option without the other.

Prefer to start in Search?

To make the home page run a search when you press Enter, choose **Search priority**. You can still start a chat with Option/Alt+Enter.

## Limitations[​](#limitations "Direct link to Limitations")

Background selection is part of the older home page experience. If your organization uses the new home page, the **Background** option isn't available.

On Google Chrome version 148 and later, Glean doesn't show its own bookmarks bar on the Glean homepage. As a result, the **Show bookmarks bar** setting may not appear in home page settings on Chrome 148+. In these cases, use Chrome's native bookmarks bar instead.

## Tips[​](#tips "Direct link to Tips")

-   Changes take effect immediately. You don't need to save.
-   You can return to the settings panel at any time to make updates.
