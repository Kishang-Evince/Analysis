On this page

Glean in Slack brings enterprise search and AI-powered answers directly into your Slack workspace. Find documents, get instant answers in channels, chat with Assistant in the sidebar, and stay on top of what matters with a personalized daily digest.

## Before you begin[​](#requirements "Direct link to Before you begin")

Your admins must install and configure Glean in Slack and enable the features you want to use. For setup instructions, see the [Glean in Slack admin guide](/administration/platform/embedded-integrations/slackbot/).

Sign in to Slack with an account known to Glean.

## What you can do[​](#what-you-can-do "Direct link to What you can do")

| Feature | What it does |
| --- | --- |
| [**/glean search**](/user-guide/embedded-integrations/slack/search-with-glean) | Search all connectors from Slack |
| [**Ask questions in channels**](/user-guide/embedded-integrations/slack/ask-questions-channels) | Get AI-powered answers directly where conversations happen |
| [**Slack sidebar**](/user-guide/embedded-integrations/slack/use-slack-sidebar) | Access the full Glean Assistant interface in Slack |
| [**Daily Digest**](/user-guide/embedded-integrations/slack/subscribe-daily-digest) | Subscribe to morning summaries of channels and topics |
| [**Code Writer**](/user-guide/embedded-integrations/slack/use-code-writer) | Turn Slack conversations into draft pull requests |
| [**Public Mode**](/user-guide/embedded-integrations/slack/understand-public-mode) | View answers shared with the entire channel |

## Get help with unavailable features[​](#if-a-feature-is-unavailable "Direct link to Get help with unavailable features")

Your Glean admin controls which Glean in Slack experiences are available:

-   If the Glean app or sidebar is not visible, ask your Glean or Slack admin to review [Slack sidebar setup](/administration/platform/embedded-integrations/slackbot/admin-guide/setup-slack-sidebar).
-   If Glean does not answer in a channel, ask your Glean admin to review [bot response settings](/administration/platform/embedded-integrations/slackbot/admin-guide/configure-bot-responses).
-   If private Slack channels or direct messages are missing from results, complete Slack authorization when prompted. If content is still missing, ask your admin to review [Slack RTS setup and content settings](/connectors/native/slack/setup/slack-rts-connector/).
