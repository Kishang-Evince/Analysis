On this page

Ask a question in a channel, open Glean in the Slack sidebar, and search for company information.

## Prerequisites[​](#prerequisites "Direct link to Prerequisites")

Your admins must install and configure Glean in Slack and enable the features you want to use. For setup instructions, see the [Glean in Slack admin guide](/administration/platform/embedded-integrations/slackbot/).

Sign in to Slack with an account known to Glean.

## Try Glean in Slack[​](#how-to-get-started-in-slack "Direct link to Try Glean in Slack")

1.  Mention `@Glean` with your question in a channel where Glean is available. See [Ask questions in channels](/user-guide/embedded-integrations/slack/ask-questions-channels).
2.  Ask a question without mentioning `@Glean`. Glean can answer proactively when your admin and the channel settings allow it. Run `/glean configure` in the channel to check **Reply to questions without being @mentioned**. For configuration details, see [Configure when Glean responds](/administration/platform/embedded-integrations/slackbot/admin-guide/configure-bot-responses#configure-when-glean-responds).
3.  Click **Glean** in Slack's top bar to open the sidebar. From there, you can chat with Glean or run supported agents. See [Use Glean in the sidebar](/user-guide/embedded-integrations/slack/use-slack-sidebar).
4.  Type `/glean` followed by a search query in any Slack channel. Glean returns results from across your connectors. For more details, see [Search with /glean](/user-guide/embedded-integrations/slack/search-with-glean).

## Personal settings[​](#personal-settings "Direct link to Personal settings")

You can control whether Glean suggests answers when you ask questions in Slack channels.

To update this setting:

1.  Go to **Glean Settings** in the Glean web app.
2.  Find the **Show suggestions for questions asked in Slack** toggle.
3.  Turn the toggle off to stop receiving suggested answers, or turn it on to re-enable them.

This setting applies only to your account and does not affect other users in your workspace.
