On this page

Glean can help you create presentations directly from a conversation. Start in chat, refine your content in Canvas, and generate an on-brand presentation.

Slide generation is enabled by default. If your company has uploaded a PowerPoint template, Glean uses it automatically. Without a template, Glean infers styling from your company's existing visual assets so the deck still feels on-brand.

## How slide generation works[​](#how-slide-generation-works "Direct link to How slide generation works")

Slide generation uses canvas as the working surface. The workflow has two stages:

1.  **Create and refine** — gather content in Glean chat, organize it in Canvas, and generate the presentation
2.  **Export** — send the generated deck to the format or destination that fits your next step

These distinct workflow stages matter because some outputs are native files generated by Glean, while others are export destinations that receive the generated deck for further editing or sharing.

### Start from chat[​](#start-from-chat "Direct link to Start from chat")

1

Ask Glean for a slide deck

In Glean, describe the presentation you want. For example: *"Create a slide deck summarizing our Q3 product launches."*

If Glean asks whether to generate the slides directly or start with an outline, choose the outline so you can refine it in Canvas first.

2

Refine content in Canvas

Glean opens Canvas with a draft outline. Edit, reorganize, and refine the content for each slide until you are satisfied.

3

Generate the presentation

Click **Create Slides** in the upper-right corner of Canvas. Glean generates a presentation based on the outline you refined in Canvas.

4

Choose the right output

After generation, choose the output that fits your workflow:

-   **PowerPoint**: Downloads an editable `.pptx` file. Best when you want the most direct editable file from Glean.
-   **Google Slides**: Exports the generated deck to Google Drive and opens it in Google Slides. Best when your team collaborates in Google Workspace.
-   **PDF**: Downloads a fixed-layout file. Best for presenting or sharing without further edits.
-   **Storybook Slides**: Generates an ordered collection of image-based slides. Best for visual storytelling where look and feel matter more than downstream editing.

Learn more about [choosing the right output](#choose-the-right-output).

### Start from an existing Canvas[​](#start-from-an-existing-canvas "Direct link to Start from an existing Canvas")

If you already have a Canvas open — for example, a brainstorm or draft you started earlier — you can use the same **Create Slides** entry point to turn that Canvas into a presentation.

## Mix and match slides from existing decks[​](#mix-and-match-slides-from-existing-decks "Direct link to Mix and match slides from existing decks")

Instead of writing a prompt from scratch, you can build a new presentation from slides in decks you already have in Glean.

1

Point Glean to your source decks

Ask Glean to build a presentation from decks you already have. For example: *"Create a QBR deck using our Q2 QBR and the latest product update deck."* Reference each deck by name, paste a link to it, or upload the file to the chat.

2

Review the suggested slides

Glean suggests which slides to keep, drop, or reorder based on the story you're building. Refine that selection with Glean in Canvas.

3

Generate the presentation

Click **Create Slides**. Glean generates only the slides it's missing, such as title, transition, or summary slides, and combines them with the reused slides into one deck.

### Limitations[​](#limitations "Direct link to Limitations")

-   **Source deck count.** You can combine slides from up to three source decks in one request.
-   **Template compatibility.** Mixing and matching works best when the source decks share the same template. Decks built on different templates can fail to merge cleanly.
-   **SharePoint-hosted decks.** To pull slides from a deck stored in SharePoint, your admin must enable [SharePoint real-time access](/connectors/native/sharepoint/real-time-access) so Glean can fetch the file.
-   **Source deck size.** Decks larger than 64 MB aren't supported for this workflow. Glean's standard [crawl and index limits](/connectors/crawler-and-indexing-limits) also apply to source decks that already live in your indexed corpus.
-   **Export destination.** Presentations built this way export to PowerPoint or Google Slides only.

## Choose the right output[​](#choose-the-right-output "Direct link to Choose the right output")

Use this table to decide which output to choose after Glean generates your deck:

| Output | Best for | Editable after export? | Where it lives | What Glean creates |
| --- | --- | --- | --- | --- |
| **PowerPoint** (`.pptx`) | Editing in PowerPoint, Keynote, or compatible tools | Yes | Downloaded to your device | A downloadable PowerPoint file |
| **Google Slides** | Collaborating in Google Workspace | Yes | Hosted in Google Drive | A copy of the generated deck exported to Google Drive |
| **PDF** | Presenting or sharing a fixed layout | No | Downloaded to your device | A downloadable fixed-layout file |
| **Storybook Slides** | Visual storytelling and image-forward slides | Limited | Downloaded to your device | Image-based slides generated from your content |

tip

Choose **PowerPoint** when you want the most direct editable file. Choose **Google Slides** when your team collaborates in Google Workspace.

You can present without exporting. See [Present directly in Glean](#present-directly-in-glean) to present the generated deck without leaving Glean.

## Present directly in Glean[​](#present-directly-in-glean "Direct link to Present directly in Glean")

After Glean generates a presentation, open the deck and click the full-screen icon to enter presentation mode. Then use the on-screen controls to move between slides.

Use this when you want to present straight from Glean. Export to one of the formats in [Choose the right output](#choose-the-right-output) when you need to edit, share, or store the deck outside Glean.

## Create interactive slides[​](#create-interactive-slides "Direct link to Create interactive slides")

Glean can also build a slide deck as interactive slides: a web-based (HTML) deck that opens in Canvas instead of a `.pptx` file. To get one, ask Glean for interactive slides. If Glean asks clarifying questions first, answer them this way:

1.  When Glean asks whether to generate the slides directly or start with an outline, choose the outline.
2.  When Glean asks which format you want for your slides, select interactive slides.

See [Interactive artifacts](/user-guide/assistant/html-artifacts) for how web-based artifacts work, and [Clarifying questions](/user-guide/assistant/glean-chat/clarifying-questions) for how Glean asks follow-up questions.

### Export interactive slides to PowerPoint[​](#export-interactive-slides-to-powerpoint "Direct link to Export interactive slides to PowerPoint")

To get an editable copy, open an eligible interactive slide deck, open the artifact export menu, and choose **PowerPoint**. Glean downloads a `.pptx` file that you can keep editing in PowerPoint or a compatible tool. Your admin controls whether this export is available.

## Branding without a template[​](#branding-without-a-template "Direct link to Branding without a template")

If your admin has not uploaded a company template, Glean infers styling from your company's existing visual assets — logos, colors, and fonts found in your company's indexed content. The generated deck still looks on-brand without any additional setup.

For the most consistent results, ask your admin to upload a company PowerPoint template. See [Slide deck generation setup](/administration/assistant/features/slide-deck-generation) for details.

## Template behavior and fidelity[​](#template-behavior-and-fidelity "Direct link to Template behavior and fidelity")

Canvas slide generation uses the company-wide PowerPoint template configured by your admin. Individual users cannot override that template from the slide-generation interface.

The **Presentation Generation** tool in Autonomous (Auto Mode) agents supports existing presentations as templates or source material. Link or attach the presentation and identify it in the agent instructions. The tool accepts up to three presentation references and creates a new deck instead of modifying the source presentations. If you do not provide a specific presentation, it uses the company template configured by your admin when one is available. The tool must be enabled by your admin and is not currently available in Workflow-mode agents or prompts.

A configured or provided presentation guides branding, themes, layouts, and relevant master slides. Because Glean generates a new deck, the result is not guaranteed to preserve every theme setting, slide master, custom layout, animation, or embedded element. Open the generated `.pptx` file in PowerPoint or another compatible application and review it before sharing.

For guidance on creating Microsoft 365 files with agents and understanding output and template limitations, see [Create Microsoft 365 files with agents](/agents/generate-files-from-templates).

## What Glean generates[​](#what-glean-generates "Direct link to What Glean generates")

When you click **Create Slides**, Glean produces a presentation that:

-   Uses your company's uploaded template for branding, layout, and formatting when one is configured, or infers styling from existing visual assets.
-   Includes slide titles, bullet points, and structured content based on what you refined in Canvas.
-   Draws on company knowledge and sources referenced in your chat to populate content.
-   Reuses images you upload or reference in the conversation, and generates supporting visuals when you don't provide them.

## Use cases[​](#use-cases "Direct link to Use cases")

Slide generation is designed to help with common presentation tasks, including:

-   **Executive briefings** — summarize strategy, metrics, or decisions for leadership.
-   **Team updates** — compile progress, milestones, and blockers into a shareable format.
-   **Product launches** — outline features, positioning, and go-to-market plans.
-   **All-hands presentations** — pull together company-wide updates from multiple sources.

## Tips for better results[​](#tips-for-better-results "Direct link to Tips for better results")

-   **Be specific in your prompt.** Include the topic, audience, and number of slides you want.
-   **Iterate in Canvas before generating.** The more polished your Canvas content, the better the final presentation.
-   **Reference internal sources.** Ask Glean to pull in data from specific documents, projects, or teams.
-   **Reuse your own images.** To put specific images in the deck, upload them or reference the document or source that contains them, then describe where they should appear. Glean reuses those existing images instead of generating new ones. Images are only available for reuse if Glean can access them, such as images you upload or that appear in sources you can open. To upload files, see [File upload](/user-guide/assistant/file-upload).
-   **Review and edit after generation.** The generated deck is a starting point. Export it and refine it in PowerPoint, Google Slides, or whichever tool your team uses.
-   **Use supported vertical alignment for tables.** If your prompt specifies vertical alignment for table cells, use `top`, `middle`, or `bottom`. Use `middle`, not `mid`, for centered content, as the unsupported `mid` value can prevent PowerPoint from opening the generated file.

## Frequently asked questions[​](#frequently-asked-questions "Direct link to Frequently asked questions")

### What export formats are supported?

Slide generation supports multiple ways to use the deck after Glean creates it:

-   **PowerPoint** (`.pptx`) is the primary editable file format generated by Glean.
-   **Google Slides** is an export destination that opens the generated deck in Google Slides.
-   **PDF** provides a fixed-layout version for presenting or sharing.
-   **Storybook Slides** provides a visual, image-based alternative.

The options you see depend on your organization's configuration and the integrations your admin has enabled.

### Is Google Slides a native generation format?

No. Google Slides is an export destination for the generated deck. You still create and refine the presentation in Canvas. Glean generates the deck, and then exports it to Google Drive and opens it in Google Slides. Choose Google Slides when you want to continue editing or sharing the deck in Google Workspace.

### Can I save a generated deck to SharePoint?

SharePoint isn't one of the export options. To save a deck to SharePoint, ask Glean in chat to upload it and include a link to the destination site or folder. For example: *"Upload this deck to the QBR folder on our Sales SharePoint site,"* followed by the folder link.

Uploads use Microsoft 365 tools, which your admin sets up. If Glean can't upload the deck, contact your Glean admin.

### Can I use my own template?

In Canvas slide generation, the presentation uses the company-wide template uploaded by your admin when one is configured, or falls back to the default admin-configured template if none is specified. Individual users cannot override this template from the slide-generation interface. Note that this tool is only supported in Autonomous (Auto Mode) agents and is not available in Workflow-mode agents or standard prompts. In an Autonomous agent with the Presentation Generation tool, you can link or attach a specific existing presentation and identify it in the agent instructions. The tool creates a new deck from that reference and does not modify the source presentation. For information about agent file generation and template limitations, see [Create Microsoft 365 files with agents](/agents/generate-files-from-templates).

### Will Glean preserve every theme and slide master from my template?

Glean uses the configured or provided presentation as a visual source for branding, themes, layouts, and relevant master slides. Because Glean generates a new deck, the result is not guaranteed to preserve every theme setting, slide master, custom layout, animation, or embedded element. Review the generated `.pptx` file in PowerPoint and make any required adjustments before sharing it.

### Why don't I see the Create Slides option in Canvas?

Your admin may have turned the feature off. Try hard-refreshing your browser. If the issue persists, contact your Glean admin or see [Slide deck generation setup](/administration/assistant/features/slide-deck-generation) for admin configuration details.

### Can I edit the presentation after it's generated?

Yes. PowerPoint exports are fully editable `.pptx` files. Google Slides exports open in Google Slides for editing. PDF and image-based outputs are better for presenting or sharing than for editing.

Changes you make in external tools do not sync back into the original Canvas outline.

### Can I build a deck from slides I already have?

Yes. See [Mix and match slides from existing decks](#mix-and-match-slides-from-existing-decks) for the full workflow and its limitations.

### Can I present the deck without exporting it?

Yes. Open the generated deck in Glean and use the full-screen and navigation controls to present it directly, without exporting to PowerPoint, Google Slides, or another destination.
