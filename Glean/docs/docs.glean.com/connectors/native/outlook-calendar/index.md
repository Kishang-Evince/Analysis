## Check for an existing connection[​](#check-for-an-existing-connection "Direct link to Check for an existing connection")

Before you start setup, check the **Admin console** for an Outlook Calendar connection. Glean can create this connection from an existing Microsoft calendar configuration. If it already exists, keep its configuration and don't create a duplicate. Contact your Glean account team before changing its credentials or indexing mode.

For email, see [Outlook](/connectors/native/outlook/). For channel and chat messages, see [Microsoft Teams](/connectors/native/teams/).
