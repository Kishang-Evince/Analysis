# Make your RFP and questionnaire history searchable in Glean

Indexes Loopio projects, including Request for Proposal (RFP) responses and security questionnaires, with permissions based on Loopio's participant lists and team membership.

Projects and entriesPermission-awareRead-only access

[See what gets indexed](/connectors/native/loopio/overview)[FAQ](/connectors/native/loopio/troubleshooting)

The Loopio connector makes your Loopio projects, including Request for Proposal (RFP) responses and security questionnaires, searchable in Glean, with permissions that match Loopio. Use the guides below to learn what gets indexed, prepare the prerequisites, and complete setup.
