# Make Git repositories searchable in Glean

Indexes content from Git repositories exposed through the Git Smart HTTP protocol, using an administrator-managed repository list.

Git Smart HTTPPersonal access tokenCSV repository listRemote-default-branch indexingAvailable to authenticated Glean users
